项目组件 · 大胆重设计（推翻方块网格）

不再「缩小旧 tile」。四套完全不同的信息架构：媒体预览轨、层级树、图标坞+详情、货架式资源墙。 左侧基础组件保持旧网格，用来反衬右侧项目组件区的新语言。

方向 1 · 媒体预览轨 Media Rail

每个组件是一张「缩略图卡」：上半区假画布预览、种类角标、下半区名称与基于关系。创建变体是卡片内文字操作，不再叠 ◇。

Figma-like 横向可滚 视觉冲击强

方向 2 · 主组件树 / 变体挂载 Tree

Unity 对齐 信息密度最高 推荐默认

选型建议（可直接拍板）

  1. 默认推方向 2（树）：和「主组件 / 变体 / 实例」语义最贴，密度最高，面板窄也能用；创建变体是行操作而非角标。
  2. 要「一眼不像旧库」选 1 或 4：1 强调预览与横向浏览；4 主/变分区货架，视觉最跳。
  3. 方向 3适合以后有真实缩略图/截图时再上，现在假预览成本高。
  4. 基础组件可继续方块；只有项目组件换语言，反差就是产品记忆点。
