推荐落地：B（九宫格 · 48px 图标）

  • 网格：继续 repeat(auto-fill, minmax(88px, 1fr)) 或固定 3 列，gap 6–7px。
  • 图标：项目组件 / 基础图标统一 40–48px（现状 24px → 至少 ×2）；SVG 描边 1.4–1.5。
  • 卡片：min-height 100–108px；上 padding 12–14 给图标，名称 12px 半粗。
  • 种类：主组件实心立方体 + 文案「主组件」；变体空心+侧标 +「变体」。
  • 创建变体：右上 20–22px，默认透明，hover/focus 显现，勿常驻描边方块压图标。
  • 若还要更大：选 C，项目区改为 2 列 56px。
