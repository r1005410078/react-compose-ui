  • 统一网格：基础 / 项目同一 minmax(64px, 1fr) 或固定 3 列，gap 4–5px。
  • 卡片：min-height 52–56px；padding 5×3；字号 10–10.5px；图标 16–18px。
  • 主组件：实心立方体；变体：空心 + 侧标；副标签「主组件 / 变体」可选（B 有、A 可省）。
  • 创建变体：右上 14–16px 图标按钮，默认 opacity: 0，hover/focus 显现；勿用常驻 24px 描边方块。
  • 交互：单击拖入、双击打开（保持）；变体按钮 stopPropagation。
  • 无障碍：按钮保留 aria-label「创建变体 {name}」；hover 隐藏时键盘 focus 仍可见。
