修剪：一下点掉一截

「剪刀」在这个产品里应该是什么：光标落在哪一截，就去掉哪一截——截的两头是它与任何别的曲线的最近交点， 没有交点就到顶点、没有顶点就到头。一条命令 TRIM，覆盖直线、折线、矩形、圆与导线， 不用先选「切割边」。本稿把每一种情况并排画出来。画布片段按 Stage 的真实 token 1:1 绘制； 绿实线圈 = 已经落地（OpenSpec 变更 add-trim-command）。与本稿的两处偏离： 拖动中命令行不换提示，仍写着「选择要修剪的一截」；接线点作为切割边的排除由既有的 isJunction 谓词承担，不另加一条。

别人怎么做

「剪刀」在不同产品里是三件不同的事：去掉一截（CAD 的 TRIM、Sketch）、在一点剪开（Illustrator、KiCad）、拿刀划开实心形状（Knife）。我们要的是第一件。

产品 · 工具一下点掉什么边界怎么定预览与批量取不取
AutoCAD · TRIM（Quick 模式） 点到的那一截，到两侧最近交点为止 所有对象自动是切割边；没有交点的对象整个删掉 无悬停预览；按住拖动画自由轨迹、或点两点画围栏，碰到的都剪；Shift 切成延伸 取：边界规则、自动切割边、拖动批量、无交点删整条。不取 Shift 延伸（本稿不做延伸）
AutoCAD · BREAK 两点之间的一截；@ 表示在一点打断 用户自己指定两点 无 不取。在一点打断正是导线剪断已经否掉的形态；两点之间的截由 TRIM 用交点表达
Fusion 360 · Sketch Trim 悬停高亮的那一截 同 AutoCAD；无交点删整条 悬停把将被删的那一截涂红；按住拖动「刷」过多条 取：悬停预览是这套交互里最关键的一处。颜色换成我们自己的
SolidWorks · Trim Entities 五档：Power trim（拖过）、Corner、Trim away inside / outside、Trim to closest 按档位：拖过 / 两条边界之间 / 最近交点 Power trim 拖动即删 只取 Power trim 与 Trim to closest 的合体。五档是五个模式，屏幕上读不出此刻在哪一档
Sketch · Scissors 点到的那一段（两个顶点之间） 顶点，不看交点 悬停高亮那一段；中间段去掉即分成两条子路径，闭合形状变开放 取它的「闭合 → 开放」与「中间段 → 两条」。边界从顶点扩成「交点或顶点」，因为接线图上的线大多没有拐点、只有交叉
Illustrator · Scissors / Knife Scissors 在点击处剪开成两条（两个重合锚点）；Knife 自由划刀切实心形状 用户点的那一点 / 刀痕 无预览 不取。剪开在屏幕上看不见；划刀面向填色图形，这里的图形绝大多数是空心线框
Figma · 顶点模式 没有剪刀。选中一段按 Delete 去掉那一段；Shift+Delete 删点并愈合 顶点 无 这正是我们今天导线段夹点上 Delete 的形态；本稿把它推广到所有折线，作为 TRIM 的退化情形
Altium · 导线 删掉一段导线到最近的节点为止（remove a segment up to that junction） 节点 无 已取（导线剪断）。TRIM 在导线上剪到节点，剩两支路的节点随即合并，与既有规则自动一致

共有的性质只有一条：用户指着的是屏幕上的一截，不是一个点、也不是一个对象。 AutoCAD 与 Fusion 的边界是交点，Sketch 与 Figma 的边界是顶点。接线图上两者都有——一条横线被三条竖线穿过没有一个顶点， 而一个矩形四条边上没有一个交点。因此边界取两者的并集，从光标处向两边走到第一个就停。

每一种情况

三格一组：之前 · 悬停（预览）· 落地。光标是拾取框加一个剪刀徽标——修剪不取点，因此没有十字线；徽标说的是「这一下会剪」，在空白处也在说。

01两条直线相交：去掉交点一侧的那一截

最基本的一档。竖线是横线的切割边，但它不需要被选：光标落在横线右半上，从落点向两边走，左边第一个停下的地方是交点、右边是端头，这一截就是「交点到右端」。竖线自己一个字节不动——切割边不是被作用的对象。落地写的是 entity.curve.set，横线的 end 挪到交点。

02线穿过矩形：挖掉中间，一条变两条

两侧都有交点时挖掉的是中间，一条线因此变成两条 Entity——左半留在原 Entity 上（id 不变，选中与撤销都还认得它），右半是新建的，呈现整份复制。这与导线剪断、搭接断线是同一条既有路径。点矩形外侧那一截则是 01 的情形：缩短。矩形是切割边而不是被作用对象，它四条边都不动。

03圆被直线穿过：圆变成弧

整圆是扫掠 360 的弧，因此剪掉一截之后仍然是同一种 kind：起始角挪到一个交点、扫掠角缩到另一个，不需要新类型，也不需要把它拍扁成多段线。一段弧被剪中间则是 02 的形态：两段弧、两个 Entity。反过来点直线在圆内的那一截，圆是切割边，直线在圆内断开——与 02 逐字相同。

04矩形的一条边：闭合变开放

矩形是四顶点的闭合多段线，一条边就是一段。这一段上没有交点，边界退到顶点——去掉整段。闭合形状去掉任何一段都变成开放折线（Sketch 的 Scissors 正是这条），closed 置 false、顶点序列从缺口处重排，因此不会凭空多出一个重合顶点。仍是同一个 Entity、同一个 rect Preset。

05有拐点的折线：中间段剪成两条，端段缩短

这正是已落地的导线剪断，推广到所有折线：中间段去掉即分成两条。一段上若还有交点，边界是交点而不是拐点（06）。

06一段上多个交点：只掉光标两侧最近的那一格

「最近」是这条规则的全部：从光标处向两边走、第一个交点就停。要掉两格就点两下，或者拖过去（07）。这与 AutoCAD 逐字相同，也是接线图上最常见的动作——母线被一排支路穿过，要断开其中一格。

07按住拖过多条：轨迹碰到的每一截一起去掉

按下不动松手是一次点选；指针离开过按下点就成了轨迹——与画布上「点亮 vs 拖动」同一条判据，不设位移阈值。轨迹只是一串屏幕点，每一段轨迹与每一条曲线求交，碰到哪一截就把它加进这一笔；同一截碰两次只算一次。松手落地一个事务（共享 mergeKey），撤销一步全回来。轨迹本身画成 accent 点画——它是「将要产出的」那一族。

08导线：剪到节点，剩两支路的节点随即合并

导线上不需要任何特判。支路是一条只有一段的导线，两头分别绑着节点与端口，因此这一截就是整条支路；它消失之后节点只剩两条支路——既有规则在同一个事务里把节点收掉、两条并成一条。绑定跟着被去掉的那一截走：端口那头的绑定随支路一起消失，这与顶点模式里「绑定端顶点删不掉」不矛盾——那条拒绝的理由是删掉顶点后绑定留在原地、下一段变斜，而这里绑定与顶点一起走，剩下的线没有任何一段变形。交叉不是交点：一条线从导线上方穿过不产生节点，但它仍是切割边——几何求交与电气连通是两件事。

09拒绝：说出来，线一个字节不动

三种拒绝互相可分，且都是说出来的——「点了没反应」与点错在屏幕上无法区分。第四种是 path（贝塞尔）：v1 不做，说明「贝塞尔路径暂不支持修剪」；它的截要解贝塞尔求交，而工程符号图导进来一个 path 都没有。

一条命令，两个入口

「货架不得成为任何能力的唯一入口」。修剪走命令行与工具栏各一格；段夹点上的 Delete 是它的退化情形。

入口怎么到此刻做什么
TRIM 命令行敲 TRIM / TR；绘图货架一格 空闲 启动会话。提示「选择要修剪的一截，或按住拖过多条（回车结束）:」。不给单键——T 已归文字工具，与 POLYGON 同一条：给一个记不住的键比不给更差
悬停 会话进行中移动指针 拾取框压住一截 那一截淡成幽灵、两头画剪口。拾取框半边长读 COMPOSE_CURVE_PICK_TOLERANCE，与点选同一个数；框的右下角挂一个剪刀徽标。没有十字线：修剪不取点
点一下 按下不动松手 拾取框压住一截 去掉那一截，一个事务，标签「修剪 {名字}」。会话留着继续剪下一截（AutoCAD 同），Enter / Escape / 右键结束
按住拖 指针离开过按下点 轨迹 轨迹碰到的每一截一起去掉，一个事务。拖动中 Escape 放弃这一笔、会话留着
撤销 Ctrl+Z 会话进行中 每一下是独立事务，逐下回退。不做会话内 U：Stage 没有撤销端口，而 LINE 的 U 是删自己建的那条，这里没有「自己建的」
段夹点 Delete 顶点模式点亮一个段条形 有夹点被会话作用着 已推广到所有折线——中间段分两条、闭合变开放，端段与唯一一段仍拒绝（缩短一截与删整条各有入口）。同一份规划、两个入口
光标要说「这一下会剪」，而拾取框说不了

等待选择对象的命令（ERASE、MOVE）在光标旁画的正是这同一个拾取框，而 ERASE 与 TRIM 都是删东西的—— 两条命令光标一模一样、差别只写在屏幕底部的命令行里，用户的眼睛此刻却在光标上（与动态输入印在光标旁是同一条理由）。 悬停预览只在压住一截时才出现，光标在空白处走的那几秒，屏幕上没有任何东西说此刻在剪。 因此在拾取框右下角挂一个剪刀徽标（AutoCAD 2015 起的 cursor badge、Fusion 与 SolidWorks 的修剪光标都这么做）。 是徽标不是换光标：拾取框必须留着——它是靶区、半边长是容差的事实来源，而一把剪刀的热点在哪儿（刀尖？交叉点？）说不清； 徽标由画拾取框的那一层一起画，系统光标的隐藏仍然只有 resolveComposeCanvasCrosshair 一个来源，不另开一条 cursor: url()。 刀尖指向拾取框（徽标在框的右下，因此整把剪刀转 45°、尖朝左上）：剪刀说的是「剪这里」，尖朝上摆在框旁边只是一个装饰。角度固定，不跟着被剪的那一段转——徽标说的是命令，不是这一截的方向，跟着转会让它在密集图上每帧抖。拒绝档（锁定、接线点、非曲线）徽标照旧——它说的是命令，不是这一下能不能成；能不能成由预览与命令行回答。

它是命令不是模式

与 ERASE、MOVE 同一档：由词启动、有明确的进出、Escape 退出，会话进行中画布照常平移缩放。它不改任何手势的语义——顶点模式的 Delete 不变，点选不变。 与 LINE 不同的是它不取点，因此拾取框不带十字线、右键不是回车而是结束。

边界规则的一句话

三处（悬停预览、点选落地、拖动落地）读同一份纯函数，否则「看见的那一截」与「掉的那一截」会不是同一截。

交点按世界坐标求（各曲线投影到盒、再乘世界矩阵，与命中、框选同一条链），弧与弧、弧与线精确求交，贝塞尔拍扁——与非等比缩放那条同一个选择。 两侧的边界与光标在同一条曲线上；切割边可以是任何曲线，含导线、圆、折线，也含自己（折线自交时另一段也是边界）。 T 形相接（一条线的端头落在另一条线身上）算交点：那正是接线图上最多的一种相接。

刻意不做的

不做延伸（Shift 切成 EXTEND）

延伸要选一个目标边界，而修剪不用。两件事共用一个键、一个提示、一个光标，屏幕上读不出此刻按下去会加长还是剪短。Shift 先留着不占。

不做「在一点剪开」（BREAK / Illustrator Scissors）

产出两个重合的端点，屏幕上与没剪之前逐像素相同，那正是导线设计里否掉的假接头。要把一条线分成两条改不同颜色，剪掉一小截再拖端点回去，或者等 EXPLODE。

不做先选切割边的两步式

AutoCAD 标准模式那一档的价值是「只有选中的边才切」——在密集图纸上少剪。但它要一个模式开关与两段提示，而 06 那条「只掉最近一格」已经把误剪的范围压到一格，多点一下比多选一步便宜。

不做刀（Knife）

刀切的是填色形状的面积，产出两个填色形状。这里的图形绝大多数是空心线框；矩形默认空心正是为了不盖住里面的符号。

待定

圆角矩形：剪口落在角弧上

04 里剪口落在直段上，角弧跟着相邻段走。若一条线恰好穿过角弧（交点在圆角里），交点没法落成一个顶点——多段线的顶点没有 bulge。v1 倾向于把交点按尖角顶点求（与「紧包围盒仍由顶点决定」同一条），代价是剪口与画出来的弧差一个圆角的距离；另一条路是拒绝并说明。

拾取框同时压住两条线

交点附近拾取框会同时盖住两条。取离光标最近的那一条，与点选一致；悬停预览因此只亮一截，用户挪一下指针就换到另一条。

剪成两条之后的名字与动画轨道

左半留原 Entity（名字、轨道、绑定都在），右半复制呈现但不复制轨道——位置轨道指着旧的盒，复制过去只会动错。与导线剪断今天的做法一致，先不改。
