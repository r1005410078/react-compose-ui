# 变更：把两处「屏幕上说不清楚」的地方说清楚

## 原因

`docs/oneline-diagram-dogfood-issues.md` 里两条可发现性问题，都不是算错了，是**没有任何东西
解释这件事**：

- **属性面板上两个字段都叫「圆角」**（O-6）：外观分组的 `borderRadius` 圆的是宿主盒，几何
  分组的 `cornerRadius` 圆的是形状本身。今天只能靠「试一个、看形状变没变」来区分，而空心
  矩形改前者是**完全没有可见效果**的——用户会以为圆角这个功能坏了。
- **符号库面板九个分类全写着 `(0)`**（O-8）：这些文件夹里各有 2～18 个 `.svg`，而计数数的
  是**已经导入成组件**的那些。数字没算错——这个面板是货架不是文件浏览器；错的是一个名字叫
  「符号库」、列着一排符号目录名、每个都写着 `(0)` 的面板，第一次看就是「符号库是空的」。
  我据此认定这条路不通，绕到底部「资源」面板才找到那些 SVG。

## 变更内容

- 外观分组的圆角改叫**「边框圆角」**（`Border radius`）：它就坐在边框颜色与边框宽度旁边，
  与字段名 `borderRadius` 对得上；几何分组保留「圆角」——那才是用户想改形状时要找的那一个。
  两处各加一句说明它作用在什么上。
- 组件库面板在**整块货架的文件夹段一个组件都没有**时，说一句「还没有导入」并指出下一步。
  **只在整块都空时说，且只说一次**：某一个文件夹是 0 而别的有货时，机制已经在屏幕上演示过
  了，那个 0 自己说得清楚；九个段各写一遍是同一句话说九遍。搜索期间不说——那时的 0 是
  「没搜到」，与「还没导入」的下一步完全不同。

- 受影响的规范：`basic-materials`（外观圆角的名称）、`component-library`（货架空态）
- 受影响的代码：

  - `packages/component-library/src/component-library/compose-component-library-panel.tsx`
