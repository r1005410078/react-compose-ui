## ADDED Requirements

### Requirement: 两个圆角字段在屏幕上可分

外观分组的 `borderRadius` 与几何分组的 `cornerRadius` MUST NOT 使用同一个标签：前者圆的是
**宿主盒**，后者圆的是**形状本身**，而空心曲线没有可见的盒——改前者**完全没有可见效果**，
用户会以为圆角这个功能坏了。

外观那一个 MUST 叫「边框圆角」（`Border radius`）：它坐在边框颜色与边框宽度旁边，也与字段名
对得上。几何那一个 MUST 保留「圆角」——那是用户想改形状时要找的那一个。

两者 MUST 各带一句说明自己作用在什么上。

#### Scenario: 选中一个矩形时两个字段名字不同

- **WHEN** 选中一个 `RECTANGLE` 画出来的矩形并看属性面板
- **THEN** 外观分组里那一行写着「边框圆角」
- **AND** 几何分组里那一行写着「圆角」
