## ADDED Requirements

### Requirement: 拍平的解算逐个给出，不合并

拍平的解算入口 MUST 为**每个**操作数各交回一条几何，MUST NOT 把它们合并成一条。

理由住在宿主那一侧——拍平逐个原地改几何——但这条约束要落在解算上：交回一条合并的几何时，
宿主除了新建一个对象之外无事可做，那正是被推翻的那种语义。

每条产物 MUST 恒是 `path`，与「拍平的产物恒是 `path`」逐字相同：只传入一条几何时同样成立。

#### Scenario: 三个操作数交回三条几何

- **WHEN** 对三个形状执行拍平解算
- **THEN** 交回三条几何，各自对应一个操作数，且顺序与操作数的层序一致

#### Scenario: 每条产物都是 path

- **WHEN** 对一个闭合多段线与一个整圆执行拍平解算
- **THEN** 两条产物都是 `path`
