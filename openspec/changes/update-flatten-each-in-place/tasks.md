> 段 1 是解算交回的形状变了，段 2 是落地规划，段 3 是端到端与门禁。

## 1. 解算逐个交回（stage-engine）

- [ ] 1.1 `resolveStageFlatten` 交回**逐操作数**的几何（每个操作数一条 `path`），
      不再交回一条合并的；区域运算那一条解算一个字节不动
- [ ] 1.2 单测（判别性）：三个形状拍平交回三条几何、顺序与层序一致；每条都是 `path`；
      一个操作数时行为与此前逐字相同

## 2. 逐个原地落地（stage）

- [ ] 2.1 `boolean-plan.ts`：拍平不再按操作数个数分支，一律逐个 `planInPlace`，
      N 条（各自已与自己的 `Hatch` 删除批成一条）再批进**一个**事务
- [ ] 2.2 拍平不挪选区；区域运算那条挪法不动
- [ ] 2.3 单测（判别性）：拍平两块颜色不同的填充 → 仍是两个 Entity、两种颜色各自留着、
      两条几何都变成 `path`；撤销一步两条一起回去

## 3. 端到端与门禁

- [ ] 3.1 端到端：画两个圆、填两块颜色不同的面，框选四个对象拍平——四个对象都还在，
      两块填充的 `fill` 各自不变，中间那块透镜**仍然透明**（这是合并语义留下的第二处症状，
      只断颜色会漏掉它）
- [ ] 3.2 门禁：lint、typecheck、单测、构建、端到端
