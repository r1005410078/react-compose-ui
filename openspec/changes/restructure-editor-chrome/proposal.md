# 变更：编辑器 chrome 整体重排

## 原因

**编辑器看起来拥挤。**顶上一行是五个格子——`[图标轨][场景图][文档标签][属性][图标轨]`——
再加两条带框的标尺，整张图纵向 8 条竖线，眼睛读到的是八个小东西。造成它的不是画布面积，
是**分割数量**：三层 Dockview 实例（外层核心 + 底部、内层左 / 画布 / 右、左栏里再嵌一层
场景 / 工具）各画各的边框，左右边缘组各有一条竖向图标轨，文档标签只在中央组头上、被两侧
面板夹着，标尺自带底色与边框。窄窗口下工具栏尾部还会被直接裁掉。

本变更只做一件事：把 chrome 收成**一个大东西分三栏**——一个 Dockview、一条横贯全宽的文档
标签条、没有图标轨的边缘组、压在图面上的标尺。纵向从 8 条竖线降到 4 条。它不引入任何新
概念，面板仍然锁死不可拖，布局仍然不序列化——那些是后续「自定义工作区」变更的事；本变更
是它们的地基：拖拽要跨栏就得是一棵树。

设计稿第 2、3、13 节（效果图与「看起来大」的账）：
https://claude.ai/code/artifact/bb4abedb-212a-4a4e-abc8-6eb6c2c19047

**不考虑兼容性**：既有规范里的三层实例、中央组承载文档、图标轨直接改写，不写迁移。

## 变更内容

### 新增

- **单一 Dockview 实例**：三层收成一棵树。左栏是场景图与工具组（基础组件、可选历史）上下分栏
  的两个普通组，右栏是属性面板一个普通组，中央为画布组，**只有底部是 Dockview 7 原生边缘组**。
  左右不能是边缘组：Dockview 的边缘组住在外层 splitview 里、包着中间那一列，而底部边缘组又住在
  中间那一列里——左右一旦是边缘组，底部就被夹在它们之间，横跨不了全宽。Strict Mode 下每组每
  面板各一个。
- **通栏文档标签条**：文档（页面、组件、资源文件）从 Dockview panel 变成编辑器会话；标签条是
  Dockview 之外的一条 `tablist`，横贯全宽；右端依次是「设计 / 动画」模式切换器、保存按钮与设置
  齿轮——前两样是**文档级** chrome，说的是「这个文档处于什么模式、保不保存」，跟着文档标签走。
  它们从画布工具栏行挪出来还有一条实际的理由：默认三栏在 1280 宽下画布列只有 600px，工具栏
  本身就要 550px，挤在同一行时尾部的绘图命令在默认窗口里就已经进「更多」了。中央画布组只承载
  画布、组头没有标签。
  标签样式沿用今天的（活动 `surface-active` 底 + `text-strong`，无 accent 条，无图标，文字 +
  未保存圆点 + ×）。
- **两侧去轨**：左右不再有竖向图标轨，折叠入口是场景组与属性组头上的按钮（收起 = 把那一侧的
  组整个藏掉），收起后沿编辑器边缘留一条 8px 把手；画布组隐藏组头（它只有一个面板，文档标签
  在通栏标签条上）；面板头高度 30px。底部边缘组保留标签条，点活动标签折叠 / 展开，折叠后只剩
  30px 的标签条。
- **标尺压在图面上**：去掉底色与边框，只留刻度与数字；刻度、游标线与吸附行为不变。
- **工具栏溢出**：宽度不足时按顺序从尾部把放不下的按钮收进「更多」菜单，不再裁掉。
- 核心面板标题「工作区」改名「编辑区」（`messages.workspaceCore`）——「工作区」这个词
  留给后续变更面向用户的概念。

### 修改

- 「四区编辑器工作区」「边缘工具区」「场景下方工具分栏」「Dockview 场景工具布局」：从三层实例
  改写为单一实例里的组；左右两侧从边缘组改为普通组；四区结构、60%/40% 分栏与最小高度不变。
- 「设置入口保持布局独立」：齿轮从左侧活动栏挪到文档标签条右端。
- 「平铺式默认画布工具栏」：按钮 30px、间距收紧；新增溢出规则；模式切换器与保存不在这一行。
- 「设计与动画模式切换器」：切换器从画布工具栏行挪到文档标签条右端，语义不变。
- 「临时布局状态」：仍不序列化，措辞改成单一实例。
- 「中央 Canvas Group 承载资源文档」删除，由「文档标签条」取代；dirty 关闭流程原样保留。

### 不做

- 面板拖拽、布局序列化、工作区概念：后续变更。
- 边缘面板按文档类型记忆展开状态：本变更原样保留（单一实例下照记）。

## 影响

- 规范：`editor-workspace-layout`（MODIFIED 8 条、REMOVED 1 条、ADDED 2 条）、`stage`
  （ADDED 1 条）。
- 代码：`packages/editor`（`workspace-layout/`、文档标签条、边缘组折叠、工具栏溢出、文案）、
  `packages/stage`（标尺样式）。`stage-engine`、`core`、`commands`、`component-library` 不动。
- 端到端：`editor-workspace.spec.ts` 大改；十二张黄金图重录（面板头 30px、通栏标签条、标尺
  样式改变了每一张的 chrome）。后续两个变更不再重录整批。
