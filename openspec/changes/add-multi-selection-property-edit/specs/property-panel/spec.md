## ADDED Requirements

### Requirement: 混合值字段

属性面板 MUST 接受一份**混合字段路径**清单，并把清单里的字段标记成「多个值」：标记 MUST 是
一句用户读得出来的话，同时 MUST 输出 `data-property-mixed="true"` 供样式与自动化寻址。

标记 MUST NOT 只靠把值留空表达——数字框留得空、色板与开关留不空，靠留空说这句话会在半数
字段上说不出口，而那一半会退化成「拿其中一个的值冒充整批」。

混合字段 MUST 照常可编辑：用户写入一个值的含义是「把这一批都设成它」，写入之后该字段不再
混合。面板本身 MUST NOT 认识选区、文档或任何业务语义——它只知道这个路径此刻不是单值。

#### Scenario: 混合字段带可读标记

- **WHEN** 宿主把 `stroke` 列进混合路径
- **THEN** 该字段行输出 `data-property-mixed="true"`
- **AND** 屏幕上有一句说明它是多个值的文案

#### Scenario: 未列出的字段不受影响

- **WHEN** 混合路径清单为空或未提供
- **THEN** 所有字段的呈现与本变更之前逐字相同

#### Scenario: 混合字段照常可写

- **WHEN** 用户在一个混合字段上选定一个值
- **THEN** 面板照常派发一次受控变更
