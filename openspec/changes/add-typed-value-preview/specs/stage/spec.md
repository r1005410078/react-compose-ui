## ADDED Requirements

### Requirement: 正在键入时预览跟着键入的值走

命令正在取点、且活动字段的缓冲里是一个可解析的数字时，Stage MUST 用它覆盖那一个字段，得到
**候选落点**，并把候选落点交给：预览查询 `preview(point)`、十字光标、橡皮筋终点、捕捉标记
与标注几何。这五处 MUST 读同一个值——它们读同一个落点是既有约束，本条只是给那个落点多了
一个来源。

覆盖 MUST 复用锁定用的那一个操作（把某一个字段替换成键入值、另一个保持不变），MUST NOT 另
写一份：锁定与本条是同一件事的两个时机——一个是「打完并按了 `Tab`」，一个是「正在打」。

**键入覆盖与锁定不可能作用在同一个字段上**：锁定的永远是非活动字段（由 `Tab` 的写法构造
保证），键入覆盖的永远是活动字段。因此两者不需要定序。

缓冲不是可解析的数字时（空、`@100,` 这类半个坐标、关键字），候选落点 MUST 等于解算落点，
也就是退回跟着光标。猜一个会让图形在打字过程中乱跳，停在上一次能解析的值则会让删掉数字之后
几何卡住不动。

候选落点 MUST NOT 提交，MUST NOT 推进会话：`preview` 是查询而不是第五种输入。

候选落点与解算落点不相等时，标注 MUST 画一条**极淡的连线**把候选落点与光标接起来——几何
停在一处而光标还在动，屏幕上需要有一句话说明这件事。判据 MUST 是这两个点不相等：锁定已经
算进解算落点里，因此这条连线只在键入覆盖时出现。

#### Scenario: 键入长度时预览线立刻变长

- **WHEN** `LINE` 取过第一个点，指针指向某个方向，用户键入 `100`（尚未回车）
- **THEN** 预览线的终点到第一个点的距离是 100
- **AND** 方向仍由指针决定

#### Scenario: 键入半径时圆立刻变

- **WHEN** `CIRCLE` 取过圆心，用户键入 `120`（尚未回车）
- **THEN** 预览的圆半径是 120，与指针到圆心的距离无关

#### Scenario: 半个坐标不改预览

- **WHEN** 用户键入 `@100,`
- **THEN** 预览与十字光标仍跟着光标，与没有键入任何东西时一致

#### Scenario: 键入不推进会话

- **WHEN** 用户在取点档键入若干字符
- **THEN** 提示文本不变，且尚未产生任何文档事务

#### Scenario: 几何停在别处时有一条连线

- **WHEN** 键入的值让候选落点离开了光标
- **THEN** 标注里多出一条从候选落点到光标的连线
- **WHEN** 缓冲清空
- **THEN** 这条连线消失
