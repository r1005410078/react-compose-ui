## REMOVED Requirements

### Requirement: CAD 文档标签

**原因**：路线图决策 1「没有第二个世界」。CAD 文档类型整体删除，中央 Canvas 组回到三种
文档标签：资源、页面、组件。

**迁移**：不写迁移器（决策 6）——没有线上 `.cad.json` 资产。残留的 `.cad.json` 在资源浏览器
里退化为普通 JSON 文件：可读、可编辑、不能作为文档标签打开。图纸画在场景（Frame）里。

## MODIFIED Requirements

### Requirement: 边缘面板按文档类型记忆展开状态

左右边缘面板的展开状态 MUST 是**当前激活文档类型**的函数，而不是工作区级的单一全局状态。

用户手动展开或收起 MUST 记入当前激活的文档类型；切走再切回同类型文档时 MUST 恢复用户的
选择，而不是重置为初值。

各文档类型的初值 MUST 一致为展开。CAD 曾经是唯一初值为收起的类型，随该文档类型一并删除；
**per-kind 记忆本身 MUST 保留**——去掉它会让面板状态在标签种类之间串台，那是一次与删除 CAD
无关的行为变化。

#### Scenario: 用户选择被记住

- **WHEN** 用户在组件标签中收起了左侧面板，切到页面标签再切回
- **THEN** 左侧面板仍是收起的
- **AND** 页面标签的展开状态不受该操作影响

#### Scenario: 初值一致为展开

- **WHEN** 首次激活任意一种文档标签且用户未曾动过边缘面板
- **THEN** 左右边缘面板都是展开的
