## ADDED Requirements

### Requirement: 进出全屏预览重新取景

预览对话框进入或退出浏览器全屏时 MUST 重新取景一次：可视区整个换掉了，此前那个取景描述的是
一块已经不存在的台面。判据与「从下拉换一块屏」逐字相同，而且换掉它正是用户按那颗按钮的目的。

触发 MUST 读 `fullscreenchange` 这一份事实，MUST NOT 只挂在那颗按钮上——用户可以用 `Esc` 或
浏览器自己的快捷键离开全屏。

取景 MUST NOT 在收到事件的那一帧按当时量到的台面算：`fullscreenchange` 早于新尺寸被量出来，
当帧取景会按**旧**尺寸算出同一个比例，缺陷原样留着，而模态形态此后不会为窗口变化再取景，
因此没有第二次机会。正确的做法是记下「下一次台面尺寸变化时取一次景」。

模态形态「窗口变化不重新取景」MUST 保持不变：那里的取景是用户用滚轮与「适应窗口」摆出来的，
而进出全屏是用户的一次显式动作，不是窗口被拖了一下。

#### Scenario: 进入全屏后取景跟上

- **WHEN** 模态形态下视图缩放停在某个比例，用户按下「全屏预览」
- **THEN** 进入全屏之后视图缩放变成让这块屏正好放进整屏的那个比例
- **AND** 此后放大缩小照常生效，它不是一个停留的档位

#### Scenario: 退出全屏后取景跟回来

- **WHEN** 用户从全屏退回模态形态
- **THEN** 视图缩放变成让这块屏正好放进对话框的那个比例

#### Scenario: 不按按钮离开全屏也重新取景

- **WHEN** 用户用 `Esc` 离开全屏
- **THEN** 同样重新取景一次
