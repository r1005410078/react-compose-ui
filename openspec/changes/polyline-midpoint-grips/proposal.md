# 提案：多段线的段中点夹点

## 为什么

用户给了一张 AutoCAD 的截图：一条选中的多段线，**每个顶点一个方块，每段中点一个条形**，
条形沿着段的方向摆。要求是「多段线顶点应该是这样」。

今天我们只画顶点，而且画的是菱形。结果是**一条画好的多段线根本加不了顶点**——想在两个顶点
之间插一个转折，只能删掉重画。

调研 AutoCAD 确认了那张图，也确认了中点夹点的用途：

| 夹点 | 悬停菜单 |
| --- | --- |
| 顶点 | 拉伸顶点 / **添加顶点** / 删除顶点 |
| 段中点（直线段） | 拉伸 / **添加顶点** / 转为圆弧 |
| 段中点（圆弧段） | 拉伸 / 添加顶点 / 转为直线 |

**我们自己的记录早就把这块地留出来了。**AGENTS 里写着：「多段线不因此获得段中点夹点：段中点
是顶点增删的天然位置，用它表示平移会把那条路堵死」。那条判断当时挡的是「拿中点当平移把手」，
留下的正是这一刀要用的位置。因此这不是推翻旧决定，是兑现它。

## 改什么

### 1. 多段线获得段中点夹点，拖它即在那里插入一个顶点

每一段（闭合多段线包括收尾那一段）在中点出一个夹点。按下并拖动它，在该段中间插入一个新顶点
并把它拖到落点。

**为什么默认动作是「添加顶点」而不是 AutoCAD 的「拉伸整段」**：拉伸整段在我们这里没有第二个
入口做不了的事——拖线身就是平移，而 AutoCAD 的三选一要靠悬停菜单，我们没有菜单。添加顶点
相反：**今天完全做不到**，而它正是我们自己的记录给中点留的用途。

### 2. 曲线的几何夹点改成方块，段中点是沿段方向的条形

形状必须能区分：两个夹点长得一样而按下去做的事不同，是最难自己发现的一类缺陷。AutoCAD 用
方块与条形，用户的截图也是。

菱形**留在运动路径上**。它当初的理由写在样式表里——「顶点菱形与时间线关键帧菱形同形」——而
那条理由只在运动路径上成立：那里的顶点**就是**关键帧。曲线的顶点不是关键帧。

## 不改什么

**不做悬停多功能菜单**（拉伸 / 添加顶点 / 转为圆弧 / 删除顶点）。那是一整套 chrome：菜单、
键盘可达、`Ctrl` 循环。这一刀先把最缺的那一项做成直接手势。

**不做「转为圆弧」。**这不是工作量问题，是**协议缺口**：我们的多段线顶点没有 bulge 字段，
一条多段线里的弧段在当前 `Curve` 协议里根本表达不出来。补它要动文档 Schema 与归一化、命中、
捕捉、渲染五条路径，必须单独立项。

**不做「删除顶点」。**AutoCAD 把它挂在顶点的悬停菜单上，而我们没有菜单；随手发明一个键位是
猜。加错了顶点用 `Ctrl+Z` 就退回去了，这条路眼下不堵。

## 影响

- `stage-engine`：多段线的夹点集合、`applyStageCurveGrip` 认识插入顶点、夹点带上呈现角色。
- `stage`：可编辑路径顶点带上角色与角度，覆盖层按角色画方块或条形。
- 样式：曲线夹点由菱形改方块；新增条形。运动路径的菱形不动。
