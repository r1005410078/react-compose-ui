# 设计决策

## 1. 网格是默认，列表留着

判据是**用户在这块面板里干什么**：他在找一个**图形**。网格把图标提到 24px 并让六个物料两行
排完，扫一眼就能认出方框、斜线、圆；列表的 16px 行首图标几乎读不出形状，它靠名字。

**不删掉列表**：文件夹段里可能有几十个符号，名字还常常是用户自己起的长英文（`Dragged Card
Focused`），那一档按名字找比按形状找快。两种排法回答的是同一个问题的两种情形，不是新旧两版。

## 2. 网格画法取「无框」

三种都画出来比过（见设计画布）：

| | 画法 | 否决理由 |
| --- | --- | --- |
| A | 无框，悬停出圆角底 | 采用 |
| B | 每格一个描边卡片 | 图标本身就是线稿方框，再套一个框就是两层方框互相打架；12 个框把这块面积切碎，图标退到第二位 |
| C | 图标坐在深色底板上、名字在板外 | 分量最重，适合以后放真实缩略图；眼下线稿撑不满那块板 |

悬停底色 MUST 与列表模式那一行**完全相同**：同一个面板换个排法，不该换一套视觉语言。

**名字区固定两行高**，而不是让格子按内容伸缩：一行的「容器」与两行的「Dragged Card Focused」
并排时，图标要落在同一条水平线上——否则同一行里的图标高低错开半行。名字**两行封顶而不是单行
截断**：单行会把 `Dragged Card` 与 `Dragged Card Focused` 变成两个一模一样的 `Dragge…`，
用户没有任何办法分辨。

**三列不是四列**：六个物料在两种列数下都是两行、高度一样，但三列的格子宽 84px，中文名与
`Rectangle` 这类词不会被拆成半个词。列数用 `auto-fill` 跟着栏宽走，拉宽自然变四列。

## 3. 排法是偏好，不是文档

判据是既有那条——**看这份事实住在哪里**：它回答「我想怎么看」，不改变文档里画了什么。因此它
写编辑器偏好、不产生事务、不进撤销历史，与工作区布局同一层。面板自身 MUST NOT 持久化它，
与货架是同一条边界：面板只发出改动，宿主决定存哪儿。

## 4. 切换入口画成看得见的按钮

候选是「只放进面板标签的右键菜单」（那里已经有「自定义物料面板…」）：省掉常驻的一行，但用户
自己发现不了——本仓库已经为这个毛病付过一次代价（不进绘图模式就看不见命令行）。因此取**面板
头一行右端两颗图标按钮**：一次点击、看得见。代价写在明处——货架没开搜索时，这一行只为两颗
按钮存在，占 22px。

## 5. 画布菜单的内容由宿主注入

`stage` **不得依赖** `@compose-ui/component-library`（架构边界：Stage 只到 `component-registry`
这一层）。因此菜单的那棵树由宿主以 prop 传进来，Stage 只负责渲染与把选中项连同世界落点报上去。

形状**照抄既有的命令注入**：注入的是「能列出什么」，会话与呈现仍住 Stage。这条已经在命令行上
跑着（宿主注入的命令与内建命令同属一份词汇表），不引入第二种机制。

**同一棵树必须只有一个来源**：编辑器用喂给物料面板的那份货架模型生成菜单树，MUST NOT 另建
一份。各建一份的症状是「面板里有、菜单里没有」，而用户读不出为什么。

## 6. 文件夹不做三级菜单

面板里文件夹本来就是**平级的一段**，菜单里多套一层会让同一棵树在两处长得不一样，鼠标还要多走
一次悬停。条目多的时候菜单自己滚动，与面板一条条往下排是同一个办法。真要在几十个符号里找，
面板的搜索比菜单快，因此菜单里 MUST NOT 再复制一个搜索框。

## 7. 落点复用既有语义

创建走**右键那一下的世界坐标**，规则一个字不改地复用「根层落点按类型分流」：容器类升格为一块
新场景，其余落进激活场景并保留世界落点。菜单不引入第二套落点规则——那正是「同一件事两套实现」
最容易漂移的地方。

## 8. 中文名只改「面板显示名」，不改「新建对象的默认名」

Preset 上 `label`（面板显示名）与 `defaultName`（新建实体的名字）本来就是两个字段。只改前者：
后者是写进**文档**的实体名，改它会动到既有页面、端到端用例，以及用户已经自己命名过的对象，
而这次要解决的问题只是「面板上还有六个英文词」。

`materials` 已经无条件输出中文界面串（属性面板分组「描边」「动画」「内容」），因此中文
`label` 与该包既有做法一致，不需要为它引入 locale 参数。

## 9. 菜单字号取 13px / 28px

不是凭手感，是量出来的——这块 chrome 的既有取值：

| 位置 | 字号 | 行高 |
| --- | --- | --- |
| 场景树行 | 13px | 22px |
| 命令行 | 13px | 30px |
| 物料行 / 面板标签 | 12px | 26px / 22px |
| 右键菜单（现状） | 14px | 32px |

菜单是浮层里的一列文本行，与场景树、命令行同族，因此取 13px；行高比行内列表宽一档（28px）
是因为它是**指针目标**，而树行还有键盘导航兜底。图标仍 16px：字缩了一档而图标是形状，跟着缩
只会更难认。
