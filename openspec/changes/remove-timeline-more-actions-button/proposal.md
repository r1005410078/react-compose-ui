# 去掉时间线行上的「更多操作」按钮

## Why

时间线左栏每条对象行和属性行的行尾都挂着一个三点「更多操作」按钮。它与右键菜单
打开的是同一份菜单、给出同一批条目，是一个纯粹的冗余入口。

代价是行尾恒定被它占住一格：占位宽度必须常驻（否则显现时行内布局跳动），于是即便
按钮不可见，属性行的数值列也要为它让出位置；属性行本来就窄，数值、颜色样值和关键帧
菱形都要挤在同一段里。左栏的信息密度换来的只是"少按一次右键"。

右键仍然覆盖全部场景，键盘也不受影响：Shift+F10 与 ContextMenu 键派发的就是同一个
`contextmenu` 事件，而每一行内部都有可聚焦的行命中按钮，键盘用户聚焦到行上即可打开。

## What Changes

- 对象行与属性行不再渲染「更多操作」按钮，右键成为唯一入口。
- 行尾不再为该按钮保留占位，属性行的数值区多出这一格宽度。
- 菜单本身、条目、语义动作与焦点恢复行为全部不变。

## Impact

- 受影响规范：`animation-panel`
- 受影响代码：`packages/animation-panel/src/animation-panel/compose-animation-panel.tsx`、
  `timeline-actions-menu.tsx`（`MoreActionsButton` 随之删除）、`styles.css`
