# canvas-kit 增量

## ADDED Requirements

### Requirement: 共享十字光标

`canvas-kit` MUST 提供两块画布共用的十字光标组件。组件 MUST 只接受屏幕坐标、两个形态布尔
（是否画十字线、是否画拾取框）、拾取框半边长与十字线长度百分比；MUST NOT 接受文档、选择集、
命令协议或任何领域类型——认识这些就该留在各自的画布包里。

十字线长度 MUST 按视口较短边取百分比（与 AutoCAD 的 `CURSORSIZE` 同义），100 时贯穿整个图面。
十字线 MUST 按一对轴向量绘制而不是写死到图面边界，使以后引入 UCS 时只需换向量来源。

同时绘制十字线与拾取框时，十字线 MUST 在拾取框处断开，框内 MUST NOT 有线穿过。

拾取框半边长 MUST 由调用方给出，MUST NOT 在组件内写死——它必须等于该画布自己的点选命中容差，
框与容差分头变化就会出现「框压住了却点不中」。

`data-testid` 前缀 MUST 由调用方给出，与既有标尺组件一致。

#### Scenario: 两种形态各自独立

- **WHEN** 调用方只要求画十字线
- **THEN** 图面上只有十字线，没有拾取框

#### Scenario: 十字线在拾取框处断开

- **WHEN** 调用方同时要求十字线与拾取框
- **THEN** 拾取框内部没有十字线穿过

#### Scenario: 拾取框尺寸来自调用方

- **WHEN** 两个调用方传入不同的拾取框半边长
- **THEN** 各自图面上的框按各自的半边长绘制

#### Scenario: 十字线长度按视口短边取百分比

- **WHEN** 调用方给出长度百分比 100
- **THEN** 十字线自光标伸到图面边界
