# cad-document 增量

## MODIFIED Requirements

### Requirement: CAD 十字光标

画布 MUST 在图面上隐藏系统指针并绘制十字光标，且 MUST 按**当前等待的输入类型**切换形态，
使用户不必读命令行就能看出这一下按下会发生什么。

绘制 MUST 使用 `canvas-kit` 的共享十字光标组件，MUST NOT 自带第二份实现——两块画布对同一个
动作给出不同的视觉反馈时，用户没有办法判断是哪一边坏了。由 `prompt.accepts` 推导两个形态
布尔的那一步留在本包：`accepts` 属于命令协议，而 canvas-kit 不认识命令协议。

形态 MUST 遵守以下对应关系：没有活动命令时同时绘制十字线与拾取框；命令等待取点时只绘制
十字线；命令等待选择对象时只绘制拾取框。命令等待的既不是点也不是选择时 MUST NOT 绘制十字
光标，并交还系统指针。

拾取框的半边长 MUST 等于点选命中容差，且 MUST 随缩放保持屏幕尺寸不变——命中判据本身是屏幕
概念，框与容差可以分头变化就会出现「框压住了却点不中」。

同时绘制十字线与拾取框时，十字线 MUST 在拾取框处断开，框内 MUST NOT 有线穿过：框覆盖的正是
用户要看清的靶区，线穿过去等于用光标盖住自己正对准的东西。

拾取框 MUST NOT 表达「当前是否命中图元」。它在空闲时恒常显示，说明的是靶区位置；命中与否
由图元自身的悬停高亮回答——高亮更靠近视线焦点，且能回答「命中的是哪一条」这个拾取框答不了
的问题。

十字光标 MUST 钉在与橡皮筋终点、坐标读数相同的解算后落点上。十字线长度 MUST 可按视口百分比
配置。指针离开图面时 MUST NOT 残留光标。

画布 MUST 只对 mouse 与 pen 指针绘制十字光标并隐藏系统光标；touch 指针 MUST NOT 绘制，也
MUST NOT 隐藏系统光标。

宿主 MUST 能关闭十字光标。隐藏系统光标会一并丢掉操作系统的光标辅助设置（放大光标、高对比
光标），而这一需求无法被探测，因此必须留一个出口。关闭时 MUST NOT 隐藏系统光标。

#### Scenario: 空闲时十字线与拾取框同时出现

- **WHEN** 没有活动命令，指针在图面上
- **THEN** 图面同时绘制十字线与拾取框
- **AND** 系统指针不可见

#### Scenario: 取点时只有十字线

- **WHEN** 命令正等待取点
- **THEN** 只绘制十字线，拾取框消失

#### Scenario: 选择对象时只有拾取框

- **WHEN** 命令正等待选择对象
- **THEN** 只绘制拾取框，十字线消失

#### Scenario: 十字线在拾取框处断开

- **WHEN** 同时绘制十字线与拾取框
- **THEN** 拾取框内部没有十字线穿过

#### Scenario: 拾取框不随命中改变

- **WHEN** 指针从空处移到图元上
- **THEN** 拾取框外观不变
- **AND** 该图元出现悬停高亮

#### Scenario: 拾取框大小等于命中容差

- **WHEN** 在任意缩放下把拾取框边缘压在图元上并按下
- **THEN** 该图元被选中
- **AND** 拾取框的屏幕尺寸不随缩放改变

#### Scenario: 触摸指针不绘制十字光标

- **WHEN** 用户用触摸在图面上操作
- **THEN** 不绘制十字光标
- **AND** 系统光标不被隐藏

#### Scenario: 宿主关闭十字光标

- **WHEN** 宿主关闭十字光标
- **THEN** 图面不绘制十字光标
- **AND** 系统光标可见

#### Scenario: 指针离开图面

- **WHEN** 指针移出图面
- **THEN** 十字光标不再绘制且不残留最后位置

#### Scenario: 换用共享组件后行为不变

- **WHEN** CAD 画布改用 canvas-kit 的共享十字光标
- **THEN** 既有的十字光标用例不改一行即全部通过
