## ADDED Requirements

### Requirement: CAD 文档标签

编辑器 MUST 支持把 CAD 文档作为第四种文档标签打开，与资源、页面、组件文档并列于中央
Canvas 组。资源浏览器 MUST 提供新建 CAD 的入口，且在 Provider 缺少创建能力时该入口
MUST 渲染为禁用而不是消失。

CAD 标签 MUST NOT 成为 Stage 宿主——Stage 的 surface 是独占的，且 CAD 有自己的编辑范式。

#### Scenario: 新建、打开、存盘、重开

- **WHEN** 用户在资源浏览器新建一份 CAD 文档
- **THEN** 该文档作为新标签打开
- **AND** 保存后关闭再重新打开，内容与保存时一致

#### Scenario: 与页面标签并存

- **WHEN** 同时打开一个页面标签与一个 CAD 标签并来回切换
- **THEN** 两者各自保持自己的会话与脏标记
- **AND** Stage 始终挂在页面标签上，不随 CAD 标签激活而重挂

### Requirement: 边缘面板按文档类型记忆展开状态

左右边缘面板的展开状态 MUST 是**当前激活文档类型**的函数，而不是工作区级的单一全局状态。
CAD 文档类型的初值 MUST 是收起；其他文档类型 MUST 保持既有的展开行为。

用户手动展开或收起 MUST 记入当前激活的文档类型；切走再切回同类型文档时 MUST 恢复用户的
选择，而不是重置为初值。

#### Scenario: CAD 默认收起

- **WHEN** 首次激活一个 CAD 标签
- **THEN** 左右边缘面板收起
- **AND** 切回页面标签时它们恢复展开

#### Scenario: 用户选择被记住

- **WHEN** 用户在 CAD 标签中展开了左侧面板，切到页面标签再切回
- **THEN** 左侧面板仍是展开的
- **AND** 页面标签的展开状态不受该操作影响
