## ADDED Requirements

### Requirement: 命令行补全读合并后的词汇表

Stage MUST 把内建绘图/编辑命令与宿主注入的定义合成的**同一份**词汇表交给命令行做补全，
与提交时解析的 MUST 是同一批定义：MUST NOT 存在「列表里有、敲出来却是未知命令」或反过来的
情形。宿主注入的定义引用不稳定，这份列表 MUST NOT 挂在渲染期的记忆化上——它只在用户打字时
才渲染。

命令行 placeholder MUST 说明 `/` 列出全部：命令行是绘图命令唯一的说明书，这条能力只有在它
自己身上写出来才可发现。列表的可访问名称 MUST 走 Stage 文案。

Stage 命令行的输入框角色因此 MUST 是 `combobox`。

#### Scenario: 列表含宿主注入的动作

- **WHEN** 宿主注入了 `GROUP`，用户在命令行键入 `/`
- **THEN** 列表同时含内建的 `LINE` 与宿主的 `GROUP`，后者带当前的不可用原因

#### Scenario: 前缀回车启动补全出来的命令

- **WHEN** 用户键入 `LI` 后回车
- **THEN** `LINE` 启动，提示为「指定第一点」，而不是「未知命令」
