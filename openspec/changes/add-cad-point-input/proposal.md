# CAD 点输入管线：坐标语法、正交与网格

## Why

路线图步骤 6 原本是「捕捉与作图范式」一整块：对象捕捉、捕捉标记、网格、正交、极轴、
坐标语法、动态输入，外加「先选后执行 / 先执行后选」。**那是两到三刀的量**，而且里面有一条
清晰的接缝：

- **不需要查询既有几何**的部分——键入坐标、正交约束、网格吸附，全都只依赖「上一个点」与设置
- **需要查询既有几何**的部分——对象捕捉（端点/中点/交点）要有 CAD 的空间索引与命中判定

本刀只做前者，并**把点的求解建成一条有序管线**，让对象捕捉在下一刀作为最高优先级的一级插进来
而不必改动调用方。这是绞杀式重构里「新路先通」的同一形状。

## What Changes

`@compose-ui/cad` 新增**纯函数的点输入管线**：

- **坐标语法**：`100,50` 绝对、`@10,20` 相对上一点、`100<45` 极坐标（距离 < 角度）。
  角度按数学惯例逆时针为正，但**屏幕 Y 轴向下**，因此实现里 y 分量取负——这一点必须写在实现旁，
  否则每个读者都要自己推一遍。
- **正交约束**：把点钳到相对上一点的水平或竖直方向，取位移较大的那个轴。
- **网格吸附**：按步长取整。
- **优先级**：键入坐标 > 正交 > 网格。**键入的坐标是精确值，不再被任何吸附改写**——用户
  打了 `100,50` 却落在 `96,48` 是最难排查的一类问题。

`@compose-ui/cad-canvas`：

- 命令行把键入的文本**先尝试解析成坐标**，失败才当关键字。语法解析属于宿主，命令状态机
  不认识坐标写法。
- F8 切换正交，命令行显示当前状态；网格按视口渲染并参与吸附。

## 本刀不做

对象捕捉与捕捉标记（需要空间索引，下一刀 `add-cad-osnap`）、极轴追踪（正交的推广，带追踪线 UI）、
动态输入浮层、选择集与「先选后执行」。**选择集是仲裁器真正开始有价值的地方**，随对象捕捉一并落地。

## Impact

- Affected specs: `cad-document`
- Affected code: `packages/cad/src/point-input/`（新增）、`packages/cad-canvas/src/`
- 不影响既有包行为
