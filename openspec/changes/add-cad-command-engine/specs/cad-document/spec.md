## ADDED Requirements

### Requirement: CAD 直线图元

CAD 文档 MUST 支持由两个点定义的直线图元。图元 MUST 声明所属图层，且该图层 MUST 存在于
文档中；校验 MUST 拒绝指向不存在图层的图元。

图元 MUST NOT 自带颜色：颜色继承所属图层（DXF 的 ByLayer）。显式颜色覆盖不在本能力范围内。

#### Scenario: 直线通过校验并可持久化

- **WHEN** 文档中加入一条两点直线并保存后重新读取
- **THEN** 校验通过且两个端点与图层归属与保存前一致

#### Scenario: 拒绝不存在的图层

- **WHEN** 图元声明的图层 id 不在文档的图层表中
- **THEN** 校验失败并给出对应机器码

#### Scenario: 端点必须是有限数值

- **WHEN** 端点坐标缺失或不是有限数
- **THEN** 校验失败

### Requirement: CAD 直线命令

系统 MUST 提供 `LINE` 命令：先取第一点，随后循环取下一点，每取得一点即产出一条连接前一点的
直线。命令 MUST 支持放弃上一个顶点与结束命令两种流程控制。

一次 `LINE` 执行产生的多条直线 MUST 作为**一个事务**提交，使一次撤销回到命令开始之前，
而不是逐段撤销。

#### Scenario: 两点画出一条直线

- **WHEN** 用户启动 LINE 并依次给出两个点后结束
- **THEN** 文档中新增一条以这两点为端点的直线
- **AND** 一次撤销即回到命令开始之前

#### Scenario: 连续取点产生折线

- **WHEN** 用户给出三个点后结束
- **THEN** 文档中新增两条首尾相接的直线
- **AND** 它们属于同一个事务

#### Scenario: 放弃上一个顶点

- **WHEN** 用户在取得若干点后选择放弃
- **THEN** 最近一个顶点被丢弃，提示回到取上一点的状态
- **AND** 在只有第一点时放弃等同于取消命令

#### Scenario: 取消不写入文档

- **WHEN** 用户在命令进行中取消
- **THEN** 文档不发生任何变化
- **AND** 预览被清除
