## MODIFIED Requirements

### Requirement: 内建工作区

编辑器 MUST 内建恰好三个工作区：页面、绘图与动画，各自带一份布局 preset、一份画布会话开关、
一份新建种子、一条工具栏货架与一条物料货架。

布局 MUST 按各自的定义铺（左侧场景 / 工具组，右侧属性，底部边缘组）：页面 = 工具组标题
「基础组件」、场景 / 工具 60%/40%（场景内容至少 160px、工具内容至少 120px）、左右两侧展开、
底部折叠、底部活动标签为资源；绘图 = 工具组标题「符号库」、活动、分栏拉高、底部边缘组折叠、
其余相同；动画 = 与页面相同，只有底部边缘组不同：`[时间线, 资源, 命令, 日志]`、**展开**、
时间线活动。

`session` 三边 MUST **逐字相同**：角度约束、增量角、网格可见与变换指示器全部同值。会话开关
本来就按工作区各记一份并在切回时恢复，默认值再分叉一次只会让「我上次把它关了」与「这个工作区
本来就是关的」在屏幕上分不开。

`session` MUST NOT 携带十字光标臂长。臂长曾经是三边唯一的差异，随后被统一，而统一之后工作区
这一处就成了一个够不着的事实来源——它已改由编辑器偏好 `crosshairSize` 承载，那里有用户可见
的控件。同一个数 MUST NOT 有两处来源。

`seeds` MUST 在两处不同：网格步长页面 8 / 动画 8 / 绘图 10，**对齐吸附页面与动画开、绘图关**；
网格吸附三边都开。工具栏货架是否相同 MUST NOT 由本能力回答——它由「工具栏货架」承载；动画的
默认货架 MUST 含「动画编辑」那一格（指向 `document.toggleAnimationMode`）。页面与动画的
`palette` MUST 是基础组件 + `components` 平铺、无搜索；绘图的 `palette` MUST 是 `Symbols` 按
子文件夹分组 + `components` + 基础组件折叠，标题「符号库」，带搜索。宿主提供 `history` 或显式
`historyPanel` 时，历史 MUST 作为工具组的第二个标签加入，未提供时 MUST NOT 显示空历史标签。

#### Scenario: 三边的会话开关逐字相同

- **WHEN** 读取三个内建工作区的 `session`
- **THEN** 三者完全相等，且都不含臂长字段

#### Scenario: 切换工作区不改变十字光标长度

- **WHEN** 用户在设置里把长度改成 100，随后在三个工作区之间切换
- **THEN** 三处的十字线都贯穿图面
