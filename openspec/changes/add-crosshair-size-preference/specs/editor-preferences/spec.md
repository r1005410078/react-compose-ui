## ADDED Requirements

### Requirement: 十字光标长度是编辑器偏好

`ComposeEditorPreferences` MUST 包含 `crosshairSize: number`——**1 到 100 的整数**，表示十字线
单侧长度占图面短边的百分比，默认 **5**。规范化时字段越界 MUST 钳到 `[1, 100]` 并取整；缺席
或不是有限数 MUST 回落**默认值**，MUST NOT 让整份偏好无效——`NaN` 表达的是「这不是一个数」，
把它当成范围端点是替用户做了一个他没表达过的选择。

这**整条照抄 AutoCAD 的 `CURSORSIZE`**：同样的取值范围、同样的「占屏幕尺寸的百分比」语义、
同样的默认值 5。5 是几十年密集图纸用出来的值，而十字线的长度是观感问题——照抄那个久经使用
的默认值比自己推一个更可靠。

它 MUST 是长度的**唯一**事实来源：工作区会话开关 MUST NOT 再携带臂长。同一个数有两处来源时，
界面上改了一处而另一处覆盖回去，用户读到的是「设置没生效」。

设置面板 MUST 为它提供**数值框与滑块两个入口**（AutoCAD 的既有解法）：滑块粗调并把可取范围
画出来，数值框精确给数。两者 MUST 联动到同一个值。

#### Scenario: 默认是 AutoCAD 的 5

- **WHEN** 宿主不提供受控 preferences 并挂载 ComposeEditor
- **THEN** `crosshairSize` 为 5，取点时十字线只在光标附近画一小截

#### Scenario: 改成任意百分比

- **WHEN** 用户在设置 › 画布里把长度改成 100，随后启动一条取点命令
- **THEN** 十字线贯穿图面
- **AND** 切换工作区 MUST NOT 把它改回去

#### Scenario: 越界与非法值

- **WHEN** 宿主回传的 preferences 里 `crosshairSize` 是 0、300、NaN 或缺席
- **THEN** 规范化后分别为 1、100、5、5，不报错

### Requirement: 十字光标的画笔与长度分开表述

设置 › 画布 › 十字光标 MUST 分成两组各自带标题与说明：**画笔**（渐隐 / 晕圈）与**长度**
（数值框 + 滑块）。

画笔那组的说明 MUST NOT 出现「贯穿图面」这类描述长度的字样——它属于长度那一组。一组选画笔
而说明里讲长度，用户会把两个选项读成长短：这正是「选晕圈期待短十字、得到长十字」的来源。

搜索 MUST 能以「长度」「臂长」命中这一节。

#### Scenario: 两组各自可选

- **WHEN** 用户在画笔里选「晕圈」，长度保持默认的 5
- **THEN** 十字线仍然只画一小截，只是换了画笔
- **AND** 用户再把长度改成 100 时，线贯穿图面且画笔仍是晕圈
