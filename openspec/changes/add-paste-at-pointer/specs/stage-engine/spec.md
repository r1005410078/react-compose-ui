## MODIFIED Requirements

### Requirement: Entity 会话剪贴板规划

Stage Engine MUST 提供与 React 无关的会话剪贴板规划：从选择规范化复制/剪切来源、解析建议粘贴
落点，以及把剪贴板转成既有 `entity.duplicate` 或移动/reparent 命令。规范化 MUST 按文档遍历顺序
保留顶层来源并去掉已被祖先覆盖的后代。剪切来源 MUST 排除锁定节点；粘贴到自身、后代或锁定父级
MUST 判定为不可用且不产生命令。

规划 MUST 接受可选的**粘贴锚点**（一个世界坐标）。给了锚点且布局快照可用时：整组来源保持
相对位置，整组的世界包围盒中心 MUST 落到锚点，落点 MUST 再过一次网格吸附（只吸网格，不找
参考线）；副本在目标父级下的位置 MUST 换算成该父级的局部坐标，目标父级是 Auto Layout 容器时
锚点只决定父级、不写位置。复制 MUST 走带显式落点的 `entity.duplicate`（显式落点压过来源坐标
与同父级错开量，副本定为 absolute）；剪切 MUST 走带 dragged 变换的 reparent，同父级也搬位置，
MUST NOT 按「顺序没变」拒绝。锚点缺席或任一来源没有盒时 MUST 退回既有行为。

#### Scenario: 规范化多选复制来源

- **WHEN** 选择同时包含容器及其子项并请求复制
- **THEN** 剪贴板只保留该容器
- **AND** 锁定节点仍可进入复制剪贴板

#### Scenario: 建议落点

- **WHEN** 目标是未锁定容器、叶节点或空选区
- **THEN** 分别解析为容器末尾、该节点之后或根级末尾

#### Scenario: 复制到指定父级

- **WHEN** 规划器为复制剪贴板提供与来源不同的父级
- **THEN** 生成的 duplicate 命令写入该父级与索引
- **AND** Absolute 副本不再额外偏移 10

#### Scenario: 带锚点复制落到指针处

- **WHEN** 两个相距 200 的来源带锚点复制，且网格步长 8 开着吸附
- **THEN** 两个副本的相对位置仍是 200，整组中心落在锚点上并吸到网格
- **AND** 来源位置不变

#### Scenario: 带锚点复制到别的父级

- **WHEN** 锚点落在另一个容器里
- **THEN** 副本成为该容器的子级，位置是锚点换算到该容器的局部坐标

#### Scenario: 带锚点剪切同父级也搬位置

- **WHEN** 剪切来源带锚点粘回同一个父级且顺序没变
- **THEN** 规划出 reparent 命令把来源搬到锚点处，剪贴板随之清空
