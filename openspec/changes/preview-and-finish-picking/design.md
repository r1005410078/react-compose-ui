# 设计说明

## `preview(point)` 是查询，不是第五种输入

会话已经有四态推进（`prompt` / `commit` / `cancelled` / `rejected`）。**不**把光标位置做成
第五种输入：`advance` 是状态机，每帧一次 `pointermove` 就推进一次会让「取了几个点」跟着鼠标
动，而撤销、放弃关键字与提示都挂在那个计数上。

查询没有这个问题：它不写会话状态、不返回 status、可以每帧调一次也可以一次不调。签名因此是
`preview?(point: ComposeCommandPoint): TEffect | null`——`null` 表示「这一步没有形状可言」
（`MOVE` 的基点、`ERASE` 的选择对象都是）。

可选而不是必需：本包零依赖、泛型，既有的宿主注入命令不该因为加了一个呈现能力而全部要改。

## 为什么形状只能由会话给出

`RECTANGLE` 的两个对角点怎么变四个顶点、`CIRCLE` 的圆心加半径点怎么变整圆、`ARC` 的三点怎么
定弧——只有命令知道。宿主要么认识每一条命令（回到按名字特判，正是命令引擎存在的理由要消灭的
东西），要么拿不到形状。

## 预览几何与橡皮筋是互斥的两种呈现

它们回答同一个问题：「松手会变成什么」。`PLINE` 的预览几何里本来就含着那条待定段，再叠一条
橡皮筋就是同一条线画两遍（两条虚线重叠会显得更粗，而那看起来像渲染缺陷）。

规则收成一句：**给得出预览几何就画几何，给不出就画橡皮筋。**不按命令种类枚举——每加一条命令
都会漏掉一处。

预览几何沿用橡皮筋的虚线与颜色：它说的是「还不是真的」，与已落地的线必须一眼可分。

## 右键的分流点在 Stage，不在引擎

判据是「有没有命令在请求输入」，而那份状态住在 Stage 自己的绘图会话里，上下文菜单也由 Stage
的根事件处理器打开。两者在同一条调用链上，因此分流是一处 `if`，不需要新协议。

引擎侧一行不改：`accept` 早就在了，右键只是它的第三个来源（前两个是命令行的空 Enter 与图面
上的 `Enter` 键）。

**判据是「一条由词启动的命令正在等一个点」**，写出来是 `awaitingPoint && gripTarget === null`。

单看 `awaitingPoint` 不够：夹点会话的提示同样接受点（「指定新位置」），因此它也会被算进去。
而夹点会话由**手势**启动、此刻正被指针拖着或刚点亮，右键在那里不表达「我说完了」——拖动中途
右键提交更是会把顶点丢在一个用户没打算落笔的地方。

`gripTarget` 是这份事实的既有来源：拾取框画不画、哪个夹点是热的、捕捉排除哪个点，读的都是它。
再引一份新状态必然漂移。

## 焦点为什么给命令行而不是图面

三件事要接：`Enter`（结束）、`Escape`（放弃）、**键入坐标**。

图面接得住前两个——Stage 的键盘能力就是为此写的（「取完点之后焦点在图面上，只把这两个键挂在
输入框上等于要求用户先点回输入框」）。第三个只有命令行接得住。

因此焦点给命令行是**严格覆盖更多**的那一个，而且它让按钮入口与键入名字入口连焦点都一致。
用户第一次点画布之后焦点自然转到图面，那之后前两个由图面接管，与今天一样。

## 提示文案而不是关键字

结束**不做成关键字**（例如键入 `E`）：那会与「空 Enter 即 accept」形成同一件事的第二个入口，
而 `PLINE` 已经有一个真关键字（放弃 `U`），再加一个只会让那一行更长、更难读。

改的是 `specifyNextPoint` 这条文案本身，`LINE` 与 `PLINE` 共用它，因此一起受益。

## 判别性

| 用例 | 钉住的东西 | 改前 |
| --- | --- | --- |
| `PLINE` 取三点后移动光标，图面上有一条**四点**折线预览 | 已取的段画出来了 | 必红（只有一段） |
| `RECTANGLE` 取一个角点后移动光标，预览是**闭合四边形**不是线段 | 形状由会话给出 | 必红（对角线） |
| 上述两条同时**没有**橡皮筋元素 | 两种呈现互斥 | 必红 |
| `MOVE` 取基点后仍画橡皮筋 | 给不出几何的命令没被顺手改掉 | 恒绿——**护栏** |
| `PLINE` 取三点后右键，得到三顶点多段线且**无**上下文菜单 | 右键结束命令 | 必红 |
| 命令不在跑时右键仍开菜单 | 分流只收走命令进行中的那一次 | 恒绿——**护栏** |
| 点工具栏按钮后焦点在命令行，按 `Enter` 不重启命令 | 结束键没被按钮吞掉 | 必红 |

两条护栏写下来，是因为这一刀最容易做过头的两个方向就是「橡皮筋从此不画了」与「右键在画布上
从此不开菜单了」。
