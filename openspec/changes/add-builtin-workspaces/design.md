## 上下文

`add-custom-workspaces` 之后工作区是「布局快照 + 会话开关」，内建只有 `page`。本变更给它加
第二个内建与两个新字段（物料货架、新建种子），并把物料面板改成按货架渲染。

## 决策

### 决策 1：会话开关只差十字光标臂长，其余差别落在货架与种子上

盘完账，两个内建在**会话开关**上真正不同的只有十字光标臂长（5 → 100）。其余四个都没有分叉的
理由：

- **变换指示器**确实与绘图冲突——它是「不画曲线几何轮廓」的直接条件，开着时一条导线会退回盒
  加八个手柄。但两边默认都是关的，而会话开关本来就按工作区各记一份、切回时恢复，冲突已经由
  既有机制挡住。把页面默认翻成开是另一个产品决定，不该作为工作区拆分的副作用发生。
- **角度约束**：极轴默认开的理由是「它不挡任何画法」，对页面同样成立。
- **网格可见**：两边都开是观感问题，没有可援引的判据。

差别因此落在另外三处：布局（工具组拉高）、货架（符号库 / 基础组件）与种子。网格步长是文档
字段，只能做种子——绘图里新建页面取 10 / 10，页面里取 8 / 8；用户按下「新建」这一下本来就在
创建文档。

**工具栏是第四处，但不由本变更回答**：它需要定义上的 `toolbar` 字段，而那是
`add-shelf-customization` 的内容。本变更因此只保证不去断言两者相同。

### 决策 2：物料面板是货架，单位是来源不是单个物料

一段货架 = Registry 的基础组件（按单项勾选，它只有四个且每个都有第二个入口）或资源里的一个
文件夹（按子文件夹分组或平铺）。选文件夹不选文件：新导入的符号自动出现；想建新分类，去资源
里建文件夹。`paletteHidden` 的 Preset 勾不出来——它们被藏是因为工具栏已提供入口，不是货架的
决定。（`add-shelf-customization` 会把这条判据**按工作区**重新界定：工具栏货架按工作区不同
之后，「工具栏已提供入口」就不再是一个全局事实。）标题与搜索是货架的字段，不是另一个面板：
同一个面板组件，两份货架。

### 决策 3：符号就是项目组件，分类就是文件夹

不发明第二种「符号」，不给 Component Asset 加 `category`。面板按组件文件所在文件夹分组，
`ComposeComponentDescriptor` 补 `folderPath`（Store 从资源条目的 `parentId` 链推出）；文件夹
来源按它筛与分组，平铺的段不读它。文件夹不存在时那一段显示「找不到」并可去掉，与工具栏跳过
未知 id 是同一条处理。

### 决策 4：种子的落点只有新建

切换时改 `document.canvas.grid` 等于在用户没动手的时候往撤销历史里塞一条。新场景尺寸两边都是
1920×1080，不进种子。

### 决策 5：对齐吸附只能是种子，不能是会话开关

工具栏那个「吸附」按钮是两样东西的合并开关，拆开看结论相反：对象捕捉（端点 / 中点 / 圆心 /
端口）恒开且不在工具栏上，绘图全靠它；网格吸附两边都开；而**对齐吸附**（Figma 式参考线）在
绘图里该关——它与特征点捕捉是姐妹查询，特征点候选**刻意不出盒的角点**正是为了避开对齐吸附的
语义，两套同时生效会在同一次取点里给出互相拉扯的答案，而接线图上每一次落笔都在找端子。

它只能是种子：`toggleSnap` 派发的是 `configureCanvas` 事务、写的是文档，而工作区的第三条硬
边界正是「不写文档」。代价写在明处——打开一份已有页面再切到绘图，对齐吸附仍然开着，要关只能
按那个按钮，而那本来就是一次进撤销历史的文档编辑。把它做成「工作区级覆盖」会更糟：同一个可见
开关有两个事实来源，用户按下按钮却看不到变化。
