## ADDED Requirements

### Requirement: 命令定义可声明提交后重开

`ComposeCommandDefinition` MUST 接受可选的 `repeat`：为真时，宿主在这条命令提交之后 MUST 立刻
以同一条命令重开一次**全新**会话。缺省为假，既有命令行为不变。

重开的会话 MUST NOT 继承上一条的任何输入。继承上一条的终点会让两点命令退化成链，而那是
`LINE` 的语义，不是这条命令的。

**这是命令定义上的一个标记，MUST NOT 做成宿主的一个模式。** 「画完之后接着画」是这条命令
自己的性质，不是画布的状态；做成模式会让同一条命令在两种模式下行为不同，而屏幕上没有任何
东西说明为什么。做成标记则「哪些命令会接着画」可以从注册处读出来。

本包 MUST NOT 实现重开——它零运行时依赖，不持有会话，`repeat` 只是一个供宿主解释的标签。

#### Scenario: 缺省不影响既有命令

- **WHEN** 一条命令的定义不声明 `repeat`
- **THEN** 提交之后命令结束，与未引入该字段时完全一致

#### Scenario: 声明之后可从注册处读出

- **WHEN** 查阅 `WIRE` 的命令定义
- **THEN** 它的 `repeat` 为真
