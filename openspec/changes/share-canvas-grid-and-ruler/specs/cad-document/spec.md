# cad-document

## ADDED Requirements

### Requirement: CAD 画布网格与标尺

CAD 画布 MUST 与页面画布共用同一个点阵求解与同一套设备像素取整规则，使同一世界坐标在两个
画布上落到相同像素。网格 MUST 绘制主线与细线两级。

网格投影间距不足以逐条显示时，画布 MUST 按二次幂 stride 抽稀为原网格的子集，MUST NOT 整片
隐藏网格——缩小正是画总图时最常用的区间，此时失去网格等于失去全部空间参照。视觉抽稀
MUST NOT 改变实际吸附步长。

CAD 画布 MUST 提供上边与左侧标尺以及原点角，标尺 MUST 显示跟随指针的游标标记，并在存在
选择集时显示其包围盒在该轴上的区间与尺寸。宿主 MUST 能关闭标尺。

网格设置 MUST 是会话级视图状态，MUST NOT 写入 `CadDocument`——CAD 是无限图纸，不带任何画布
设置。

#### Scenario: 缩小后网格抽稀而不是消失

- **WHEN** 用户把视图缩小到网格投影间距不足以逐条显示
- **THEN** 画布仍显示网格，只是按二次幂 stride 隐藏了部分格线
- **AND** 图元仍然吸附到原始配置的步长

#### Scenario: 刻度与网格线落在同一位置

- **WHEN** 在任意缩放与设备像素比下渲染
- **THEN** 同一世界坐标的标尺刻度线与画布网格线覆盖同一条 1 CSS px 带

#### Scenario: 标尺游标跟随指针

- **WHEN** 指针在图面上移动
- **THEN** 两条标尺各显示一个对应当前指针世界坐标的游标标记
- **AND** 指针离开图面后游标消失

#### Scenario: 网格设置不进文档

- **WHEN** 用户改变网格显示或步长后保存
- **THEN** `.cad.json` 的内容不因此改变
