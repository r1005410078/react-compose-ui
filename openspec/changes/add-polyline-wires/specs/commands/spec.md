## ADDED Requirements

### Requirement: 取点提示可钉死角度约束

`ComposeCommandPrompt` MUST 接受可选的 `constrain`：这一步的落点被钉死在某种角度约束上，
与会话级的角度约束设置无关。缺席即跟随会话级设置。

**约束与辅助是两回事。** 会话级的角度约束是用户的**偏好**（关 / 正交 / 极轴），它辅助用户落在
整齐的方向上；而有些命令的产物按行业规范**必须**是某个方向——导线在一次接线图与 PCB 上一律
横平竖直，斜着走的导线不是「用户的选择」而是一张画错的图。

它 MUST 由**提示**声明，MUST NOT 由宿主按命令 id 判断：哪一步该被钉死只有命令知道（`WIRE`
的第一个点没有上一点、量不出方向，因此不钉；从第二个点起才钉），而宿主拿到的只是一个提示。

钉死的 MUST 只是落点解算里**角度约束那一档**，MUST NOT 改变管线次序——`键入 > 捕捉 > 网格 >
角度约束` 原样成立。

本包 MUST NOT 实现约束本身：它零运行时依赖、不认识几何，`constrain` 只是一个供宿主解释的标签。

#### Scenario: 缺席即跟随会话设置

- **WHEN** 一步提示不声明 `constrain`
- **THEN** 该步的落点按会话级角度约束解算，与未引入该字段时完全一致

#### Scenario: 声明之后压过会话设置

- **WHEN** 会话级角度约束为关，而这一步声明了正交
- **THEN** 该步的落点仍被投影到轴向上
