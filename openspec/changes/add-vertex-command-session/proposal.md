# 顶点取点走命令那一套

## Why

三条实测（探针跑完即删）。

### 一、几何编辑期间命令行不说话，还留着上一条命令的残句

```
双击一条线进入几何编辑  ->  命令行提示 = 「已取消」
```

「已取消」是上一条 `LINE` 被 `Escape` 掉时留下的。用户此刻正站在一个**会取点**的状态里，
而命令行在说一件已经过去的事。

### 二、键入坐标是死路

```
几何编辑中键入 100,50 ↵    ->  「未知命令」
```

这违反仓库已有的一条不变量——「键入坐标与指针取点共用同一条求解」。今天顶点是 Stage 里
**唯一**一处「人在取点、键盘却进不来」的地方：`LINE`、`ARC`、`MOVE` 全都能键入精确坐标，
唯独「把这个顶点放到 `100,50`」做不到。

路线图决策 11 写的是「模式内 取点走点输入管线」，而顶点只接了一半——指针那一半。

### 三、夹点的单击槽位今天是空的

```
在 end 夹点上原地按下松开    ->  几何位移 (0, 0)，不产生撤销记录
偏 4 像素原地按下松开        ->  同上
```

两次都是 0，因为网格把落点吸回了原来那个格点。关掉网格吸附、或换一个细网格时，它就变成
一次**无意的微移**——这不是两件事，是同一件事的两面：这个槽位没有语义。

AutoCAD 在这个槽位上放的正是缺的那件事：单击夹点把它**点亮**，命令行随即进入
`** STRETCH ** Specify stretch point or [Base point/Copy/Undo/eXit]:`，此后既可以再点一下，
也可以键入坐标。拖动照旧。

## What Changes

- **按下夹点即开一条一点会话**，提示「指定新位置」。松手时指针若一步没动，会话**留着**
  （夹点点亮）；动过就照今天提交。拖动的手感因此一点不变，而「按一下再输坐标」多出来。
- **点亮期接既有的取点通道**：橡皮筋自夹点原位置起、十字线钉在解算后的落点、捕捉标记照旧、
  `F8` / `F3` 照旧；键入的坐标不被捕捉、正交或网格改写。
- **点亮的夹点画成热的**（AutoCAD 的 `GRIPHOT`）。这**推翻**了「不做热夹点」那条记载——
  它的理由（「夹点跟着预览几何走在光标底下，那个信息已经在屏幕上了」）只对**拖动**成立。
  点亮期夹点停在原位、光标在别处找目标点，屏幕上没有任何东西说得出「下一个点会挪哪个顶点」。
- **`Escape` 分两级**：点亮时先熄灭夹点，再按一次才退出几何编辑。与 AutoCAD 的
  热夹点 → 温夹点 → 取消选择同构。
- **进入会话时清掉残留 notice。**
- **拾取框的规则收成一句**：只在**既没点亮也没拖动**时画。今天写成「未拖动时画」，多出的
  第三态会让框在点亮期继续挡着落点。
- **加一条 `VERTEX` 命令**（别名 `VE`）进入几何编辑。理由是这一刀自己制造的不一致：它的全部
  意义是让键盘够到顶点（键坐标精确落点），可**进去**仍然只能鼠标双击。它复用 `ERASE` 那条
  两次序共用的状态机——启动时已选好一个可编辑曲线就当场进入，没选好就提示选择对象；选中不是
  恰好一个时以 `rejected` 说明，而不是什么都不发生。

## Impact

- 规范：`stage` 的「曲线几何编辑会话」一条 MODIFIED，新增「顶点取点是一条命令会话」；
  `stage-engine` 新增「夹点取点会话」。
- 代码：`packages/stage-engine`（`createStageVertexSession` 与 `VERTEX` 命令、
  `planStageDraftingEdits` 多认一种效果）、`packages/stage`（`use-stage-drafting` 开放按会话
  对象启动、`use-stage-geometry-editing` 的点亮状态、热夹点样式与三态拾取框）。
- 破坏性：无。既有的拖动路径、`entity.curve.set` 载荷与撤销粒度都不变。

## Non-Goals

- **不叫 `PEDIT`。**AutoCAD 的 `PEDIT` 还管闭合、合并、拟合与样条化，拿一个已有确切含义的词
  去做一件小得多的事，比另起一个词更糟。`VERTEX` 不是 AutoCAD 的词，但它说的正是它做的事。
- **`VERTEX` 不接管双击。**双击仍是它自己的入口，两者产出同一个会话。
- **不做 AutoCAD 的夹点关键字**（`Base point` / `Copy` / `Undo`）**与模式轮换**（空格在
  `STRETCH` / `MOVE` / `ROTATE` / `SCALE` / `MIRROR` 之间切）。v1 是一个点。
- **不做顶点增删。**路线图「未定的决策」里已经记着：它要的是一种新手柄，不是一条新会话。
- **不改捕捉的优先级，也不改点级排除的粒度。**点亮期排除的仍然只有被点亮那个顶点的原位置，
  理由与拖动期同一条：不排除的话，指针回到附近就被吸回原处。
