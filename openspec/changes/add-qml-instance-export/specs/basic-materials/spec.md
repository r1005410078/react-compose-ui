## ADDED Requirements

### Requirement: 组件实例准备管线是共享的纯函数

`@compose-ui/materials` MUST 公开一个不含 React 的组件实例准备函数：从实例的 Renderer props、实例盒
与祖先组件引用，产出「可直接求解的嵌套文档 + 内容适配方式与比例 + 翻转比例」，或可判别的失败原因
（快照无效、覆盖无效、循环引用、嵌套过深）。组件实例渲染器 MUST 调用该函数而不是自行实现这些步骤，
步骤顺序 MUST 保持「快照 → 实例覆盖 → 动画采样 → 根锚到原点 → 按盒对齐根尺寸」。

#### Scenario: 渲染器与准备函数结果一致

- **WHEN** 一个带实例覆盖、动画播放头与 `contentFit: scale` 的实例分别经渲染器与准备函数处理
- **THEN** 渲染器求解的嵌套文档与准备函数返回的文档相同，内容缩放比例相同

#### Scenario: 循环引用

- **WHEN** 准备一个其组件引用已出现在祖先链里的实例
- **THEN** 准备函数返回原因为循环引用的失败，渲染器据此显示既有的循环引用状态
