## ADDED Requirements

### Requirement: 组件实例按嵌套求解结果内联展开

导出 MUST 接受按实例复合地址索引的可选嵌套求解结果（嵌套文档、快照、内容适配、翻转）。提供时，
实例 MUST 内联展开为一棵子树：外层按实例盒裁剪，有翻转时绕盒中心镜像，`contentFit: scale` 时按根的
自然尺寸摆放并以原点为基准整体缩放，其下嵌套文档的子树 MUST 使用与页面一级相同的映射规则。实例内部
对象的 QML `id` MUST 带实例前缀以保证同一组件的多个实例互不冲突，`objectName` MUST 写复合地址。
未提供或准备失败的实例 MUST 导出为同尺寸占位并给出诊断。

#### Scenario: 同一组件的两个实例

- **WHEN** 场景中有同一个组件的两个实例
- **THEN** 两棵子树的内部对象 id 互不相同，`objectName` 分别是各自的复合地址

#### Scenario: 内容缩放与翻转

- **WHEN** 一个实例 `contentFit` 为 `scale`、`flip` 为 `x`
- **THEN** 导出包含绕盒中心的水平镜像与以原点为基准的缩放
- **AND** 像素对比与预览一致

#### Scenario: 嵌套实例

- **WHEN** 组件内部还有另一个组件的实例
- **THEN** 内层实例按 `外层/内层` 的复合地址取得求解结果并同样内联展开

#### Scenario: 缺少求解结果

- **WHEN** 某个实例在输入中没有对应的嵌套求解结果
- **THEN** 该实例导出为同尺寸占位并给出包含其地址的诊断，其余实例照常展开

### Requirement: 编辑器导出时逐实例准备与求解

编辑器的「导出为 QML」MUST 对场景中的每个组件实例（含嵌套实例）调用共享的准备函数，并用与预览同一个
测量端口工厂求解嵌套文档，再把结果交给导出器。导出期间 MUST 给出进行中的提示，完成后交付文件。

#### Scenario: 导出含实例的场景

- **WHEN** 用户导出一个含组件实例的场景
- **THEN** 下载的 QML 中实例展开为子树而不是占位
- **AND** 导出完成前界面显示进行中的提示
