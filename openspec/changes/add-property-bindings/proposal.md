# 变更：增加属性变量绑定与自适应操作轨道

## 原因

属性面板当前把存在性、重置和集合操作直接塞入 36px 操作列，多操作会被静默裁剪；同时属性只能
保存字面值，无法将页面或全局变量绑定到单个逻辑输入。

## 变更内容

- 将操作列改为最多三槽并带可访问溢出菜单的自适应操作轨道。
- 为属性面板增加与字面值分离的受控单向变量绑定协议、默认选择器和纯解析函数。
- 允许自定义 renderer 声明多个子绑定目标，覆盖复合数值与 ECharts 内部输入。
- 在示例应用中提供确定性的页面/全局变量和 Canvas 联动流程。

## 影响

- 受影响的规范：`property-panel`
- 受影响的代码：`@compose-ui/property-panel` 公共 API、属性树渲染、示例应用与 Chromium E2E
- 兼容性：绑定配置为可选；未提供时现有 Schema、renderer、受控值和 DOM 行为保持兼容
