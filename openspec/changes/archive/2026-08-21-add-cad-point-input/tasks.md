## 5. 实施中的发现与偏离

- [x] 5.1 **参照点必须由会话给出，不能让宿主记账**：「放弃(U)」会退回上一个顶点，宿主自行记住
      「最后送进去的点」会与会话失步，随后的正交与相对坐标全部以错误的基准求解。因此
      `CadCommandEffect` 增加 `reference` 字段，画布从预览里读。已补一条用例钉住。
- [x] 5.2 **点输入管线不用文档里的 `CadPoint`**：后者继承 `JsonObject`（带索引签名），普通的
      `{ x, y }` 无法赋值。管线处理的是尚未落进文档的候选点，另立结构类型 `CadInputPoint`，
      否则调用方要到处重建对象。
- [x] 5.3 **网格尺寸改用 ResizeObserver 进 state**，不在渲染期读 ref：首帧没有元素，且面板改变
      大小时网格必须重画。lint 的 `react-hooks/refs` 正好把这个真问题挡了下来。
- [x] 5.4 网格疏密按**屏幕间距**而不是缩放比例判定：同一个 zoom 下步长 1 与步长 100 的疏密差两个
      数量级，用 zoom 做门槛会在其中一边失效。
- [x] 5.5 键入文本只在**本步接受点**时才尝试解析坐标，否则 `100,50` 会在只收关键字的步骤上被
      误解成一个点。
- [x] 5.6 jsdom 既没有 `ResizeObserver` 也不给真实矩形，两者都要在测试夹具里补。
