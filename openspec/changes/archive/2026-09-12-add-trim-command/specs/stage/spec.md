## ADDED Requirements

### Requirement: TRIM 的悬停预览与拖动

Stage MUST 在命令等待 `pick` 时，随指针移动解算光标底下那一截并画出预览：那一截 MUST 淡成
幽灵（按 Entity 自己的描边色改成点画、并压淡到明显可辨），两头各画一道**与线垂直的短划**作为
剪口。剪口 MUST 用自己的颜色 token，MUST NOT 借 `danger`（那是失效）、捕捉橙（那是吸上了没有）
或 accent（那是选中了）。被去掉的那一截 MUST NOT 换色：一条红导线上涂任何颜色都读不出来，
淡掉在每种墨上都读得出来。指针离开图面或没有压住任何曲线时 MUST 不画。

预览 MUST 读与落地**同一份**解算（`resolveStageTrimPiece`）。预览 MUST 在 `useLayoutEffect`
里算——它读住在 ref 里的会话状态，且要在绘制之前跑完。

`pick` 的命中 MUST 按拾取框容差取**离光标最近**的曲线 Entity，与点选一致；MUST NOT 改动选择集。
按下不动松手 MUST 是一次 `pick`；**指针离开过按下点** MUST 进入拖动，判据与夹点「点亮 vs 拖动」
相同，MUST NOT 设位移阈值。拖动中轨迹 MUST 画成 accent 点画（它是「将要产出的」那一族），
轨迹碰到的每一截 MUST 都画成幽灵；松手时全部目标 MUST 作为**一次** `pick` 推进（同一截碰两次
只算一次）。拖动中 `Escape` MUST 放弃这一笔而会话留着，不在拖动中 `Escape` 退出命令。

等待 `pick` 时右键 MUST 等同回车（结束命令）而 MUST NOT 弹上下文菜单，与取点命令同一条。

MUST 拒绝并在命令行说明的四档互不相同：锁定、接线点、非曲线、`path`。悬停在这四类上 MUST 不出
预览；点下 MUST 说明。拒绝 MUST NOT 结束会话。

#### Scenario: 悬停出预览、离开即消失

- **WHEN** `TRIM` 进行中指针在非 100% 缩放下压住一条被竖线穿过的横线的右半
- **THEN** 横线交点右侧那一截画成幽灵，交点处画一道剪口
- **AND** 指针移到空白处后预览消失

#### Scenario: 点一下即落地、会话留着

- **WHEN** 在预览可见时按下不动松手
- **THEN** 那一截消失，一个事务
- **AND** 命令行仍提示选择要修剪的一截

#### Scenario: 拖过多条一个事务

- **WHEN** 按住并拖过四条线、松手
- **THEN** 轨迹碰到的四截在同一个事务里消失，撤销一步全部回来

#### Scenario: 拖动中 Escape 放弃这一笔

- **WHEN** 拖动中按 `Escape`
- **THEN** 轨迹与幽灵消失、文档不变，命令仍在进行

#### Scenario: 不改选择集

- **WHEN** 选中一个矩形后启动 `TRIM` 并剪掉一条线的一截
- **THEN** 选区仍是那个矩形

#### Scenario: 接线点在命令行说明

- **WHEN** 拾取框压在一个接线点上按下
- **THEN** 命令行说明接线点不能修剪，文档不变，命令仍在进行

## MODIFIED Requirements

### Requirement: Stage 十字光标

Stage MUST 在绘图命令进行期间绘制十字光标，并 MUST 按**当前等待的输入类型**切换形态：命令
等待取点时绘制十字线，命令等待选择对象或等待 `pick` 时绘制拾取框，其余情形不绘制。

提示声明了 `badge` 时，Stage MUST 在拾取框的右下角画出徽标，**刀尖指向拾取框**；徽标 MUST 由
画拾取框的那一层按**同一个**解析结果画（解析说不画时徽标也不画），MUST NOT 另开一条
`cursor: url()`。它是徽标而不是换光标：拾取框必须留着——它是靶区、半边长是容差的事实来源，
而一把剪刀的热点在哪儿说不清。角度 MUST 固定，MUST NOT 跟着光标底下那一截转：徽标说的是
命令，不是这一截的方向。等待 `pick` 时 MUST NOT 画十字线：修剪不取点。

**空闲时 MUST NOT 绘制**：页面编辑器的静息光标是箭头，十字光标只在「正在取点」这件事发生
时出现。形态推导 MUST 留在本包，共享组件 MUST NOT 认识它。

绘制期间 MUST 隐藏系统光标。画了十字线却留着系统箭头会让屏幕上出现两个光标，而用户会以为
十字光标失效了。绘制与隐藏 MUST 由同一个判定驱动，MUST NOT 各判一次。**反向同样违规**：
收走了系统光标却没画十字线时，屏幕上一个光标都没有，而那通常发生在用户最需要看清落点的
那一下。因此隐藏 MUST 只有一个来源，MUST NOT 由「取点覆盖层是否挂载」之类更宽的条件驱动
——覆盖层还承载捕捉标记与橡皮筋，它挂着的时候十字光标未必在画。

指针位置的跟踪 MUST 覆盖**手势进行期**。手势会在 Stage 根节点上获取指针捕获，而按 Pointer
Events 规范，获取捕获会向原目标链派发 `pointerleave`，此后的 `pointermove` 一律重定向到捕获
元素。跟踪因此 MUST NOT 只挂在图面上——那样每次拖动都会先收到一次 `pointerleave` 把位置清空，
再也收不到后续移动，症状是**一拖动十字线就断**。

绘制 MUST 复用 `@compose-ui/canvas-kit` 的共享十字光标，MUST NOT 另写一份。十字线长度 MUST
按视口较短边取百分比而不是贯穿整个图面；同时绘制两者时 MUST 在拾取框处断开；touch 指针
MUST NOT 绘制，也 MUST NOT 隐藏系统光标；指针离开 Stage 时 MUST NOT 残留光标。

十字光标 MUST NOT 绘制在一个**本次跟踪开始之前**观测到的指针位置上。指针位置只在需要绘制
时才跟踪，因此上一次会话留下的那个坐标可以任意陈旧——它是上一条命令最后一次点击的地方，而
不是指针现在所在的地方。症状是会话一开始十字线停在别处，等用户动一下鼠标才跳到正确位置，
而双击进入几何编辑时这一跳尤其显眼：起点是很久以前的某个点，终点是用户刚刚双击的地方。

因此：跟踪停止时 MUST 清掉已记录的位置；由指针事件启动的会话 MUST 用**该事件**的位置播种；
无从得知指针位置时（例如从命令行敲入命令）MUST NOT 绘制，直到收到第一次 `pointermove`。
浏览器不提供查询指针当前位置的接口，因此「先不画」是这一档唯一诚实的答案，而它严格好过
画在一个错误的地方再跳过去。

宿主 MUST 能关闭十字光标，并 MUST 能配置十字线长度百分比与拾取框半边长。

**Stage 的拾取框 MUST NOT 参与任何命中判定**，它只表达靶区位置——判定始终由物料的 stroke
完成，框只是把同一个数画出来。点选那一档的拾取框半边长默认值 MUST 为
`COMPOSE_CURVE_PICK_TOLERANCE`，MUST NOT 另取一个数：这一档用户选的就是曲线，框比真实容差
大好几倍等于教用户瞄错。`pick` 那一档 MUST 用同一个数：它的命中读的正是这个容差。

拾取框与顶点模式那一档 MUST NOT 为了看起来一样大而互相迁就：两档各自 MUST 表达自己那一档
真实抓得到的范围（顶点模式派生自夹点命中半径，见另一条 Requirement）。夹点本来就是比发丝线
更大的目标，两个框不一样大是对的。

#### Scenario: 取点时画线并收走系统光标

- **WHEN** 绘图命令正等待取点，指针在图面上
- **THEN** 图面绘制十字线
- **AND** 图面上的系统光标不可见

#### Scenario: 等待选择对象时只有拾取框

- **WHEN** 绘图命令正等待选择对象
- **THEN** 图面绘制拾取框，没有十字线

#### Scenario: 等待 pick 时是拾取框加徽标

- **WHEN** `TRIM` 正等待 `pick`，指针在图面上
- **THEN** 图面绘制拾取框与剪刀徽标，没有十字线
- **AND** 系统光标不可见
- **AND** 指针离开图面后两者都不画

#### Scenario: 会话开始时不画在陈旧位置上

- **WHEN** 一条命令结束后指针移动过，随后从命令行启动新命令且不再移动指针
- **THEN** 图面不绘制十字光标，直到指针再次移动

#### Scenario: 由指针事件进入的会话就地绘制

- **WHEN** 双击一条曲线进入几何编辑会话，之后不移动指针
- **THEN** 十字光标绘制在该双击点上

#### Scenario: 拾取框与曲线容差同源

- **WHEN** 宿主未配置拾取框半边长，绘图命令正等待选择对象或 `pick`
- **THEN** 框的半边长等于 `COMPOSE_CURVE_PICK_TOLERANCE`

#### Scenario: 拖动期间十字线不断

- **WHEN** 在绘制十字光标的状态下按下并拖动指针，手势因此取得指针捕获
- **THEN** 整个拖动过程中十字线持续绘制并跟随指针
- **AND** 任何时刻「有十字光标」与「系统光标被收走」都同真同假

#### Scenario: 空闲不绘制

- **WHEN** 没有活动的绘图命令
- **THEN** 图面不绘制十字光标
- **AND** 系统光标可见

#### Scenario: 宿主关闭十字光标

- **WHEN** 宿主关闭十字光标，绘图命令正等待取点
- **THEN** 图面不绘制十字光标
- **AND** 系统光标可见

### Requirement: 导线在顶点模式里的 Delete

Stage MUST 按**此刻有没有夹点被会话作用着**把 `Delete` 与 `Backspace` 分流，判据读的是拾取框
画不画读的**同一份事实**：没有夹点被作用着时删整个 Entity，有夹点被作用着时按那个夹点的种类
决定。顶点模式里**没有**夹点被作用着时 MUST 仍然删掉整条导线——进了这个模式就删不掉它，是一个
没有出口的状态。

这一档 MUST 分成下面几种落地，说明 MUST 各不相同——「按了没反应」与「按错了地方」在屏幕
上无法区分，而这几种情形的补救办法各不相同：

| 此刻 | `Delete` |
| --- | --- |
| 端点方块被点亮，该端自由 | 删掉那个顶点 |
| 端点方块被点亮，该端绑在端口上（导线） | 拒绝，说明那一端绑着端口 |
| 段条形被点亮，那是开放折线的中间段 | 剪断那一段，导线或普通折线都一样 |
| 段条形被点亮，那是闭合折线的一段 | 去掉那一段，折线变开放 |
| 段条形被点亮，那是端段或唯一一段 | 拒绝，说明只有中间的段可以剪断 |
| 直线的平移夹点被点亮 | 拒绝，说明这个夹点不是顶点 |

只剩两个顶点时的顶点下限拒绝照旧，说明与上面各种都不同。

Stage MUST 向引擎注入「这一端绑着什么」与「这是不是导线」两个判据：引擎不认识导线，与夹点求解
的轴对齐选项是同一条既有边界。判据 MUST 读既有的「是不是导线」谓词，与导线 Preset、端口捕捉、
夹点会话钉死正交读的是同一个答案——各判一次的症状是「这条线在顶点模式里是导线、在画的时候不是」。
「是不是导线」在这一档 MUST 只决定绑定怎么继承，MUST NOT 决定能不能剪。

**拒绝与落地 MUST 分开**：落地之后被作用的那个夹点不再存在，它的取点会话跟着结束；而拒绝时
几何一个字节没动、夹点还在，顺手结束会话会把刚说出来的那句理由用「已取消」冲掉——用户按了一个
键，屏幕上只剩一句与他的动作无关的话。因此这一档 MUST 交出三种结果而不是一个布尔：落地、拒绝、
以及「这里没有答案」（交回既有级联，删整个 Entity）。

剪断产出的两条 MUST 在同一条事务里写入，撤销一步 MUST 回到一条。

#### Scenario: 点亮中间段按 Delete 剪断

- **WHEN** 在非 100% 缩放下双击一条四顶点直角导线，原地单击点亮中间那一段的段夹点，按 `Delete`
- **THEN** 那一段从图上消失，文档里多出一条导线
- **AND** 一次撤销回到一条

#### Scenario: 普通折线点亮中间段按 Delete 也剪断

- **WHEN** 双击一条普通四顶点折线，点亮中间那一段的段夹点，按 `Delete`
- **THEN** 那一段从图上消失，文档里多出一条折线，两条都不带 `Wire`

#### Scenario: 矩形点亮一条边按 Delete 变开放

- **WHEN** 双击一个矩形，点亮一条边的段夹点，按 `Delete`
- **THEN** 那条边消失，矩形变成三段开放折线，仍是同一个 Entity

#### Scenario: 点亮绑定端的顶点按 Delete 不动几何

- **WHEN** 双击一条起点绑在符号端口上的导线，点亮起点方块，按 `Delete`
- **THEN** 命令行说明那一端绑着端口
- **AND** 该导线的顶点数与两端绑定都不变

#### Scenario: 端段上的段夹点按 Delete 说明原因

- **WHEN** 点亮一条三顶点导线第一段的段夹点并按 `Delete`
- **THEN** 命令行说明只有中间的段可以剪断
- **AND** 该导线的几何不变

#### Scenario: 顶点模式里不点亮任何夹点仍删整条

- **WHEN** 双击一条导线进入顶点模式，不点亮任何夹点，按 `Delete`
- **THEN** 整条导线被删除

#### Scenario: 拒绝之后夹点还亮着

- **WHEN** 点亮一条导线绑定端的顶点并按 `Delete`
- **THEN** 命令行显示的是那句理由，而不是「已取消」
- **AND** 那个夹点仍被会话作用着

#### Scenario: 各种说明互不相同

- **WHEN** 依次触发绑定端拒绝、端段剪断拒绝、顶点下限拒绝与直线平移夹点的拒绝
- **THEN** 命令行给出四句互不相同的说明
