## ADDED Requirements

### Requirement: CAD 动画清单落在文档级

`CadDocument` MUST 在**顶层**携带动画清单，MUST NOT 模仿页面文档把清单挂在某个分区实体上——
CadDocument 没有 Frame，而一份图纸就是一个时间线作用域。

关键帧轨道 MUST 仍然住在被动画 Entity 的 `Animation` Component 上，与页面文档完全相同：
删除一根导线时它的轨道随之消失、复制一个符号时动画随之复制，两处都不需要补偿代码。

清单缺省 MUST 读作空数组，`schemaVersion` MUST NOT 因此改变。清单条目的 id 为空或重复、
时长不是有限正数、播放模式不合法时 MUST 校验失败并给出稳定机器码。

轨道指向不存在的 Component 时 MUST NOT 判为校验失败——采样本就静默跳过这种轨道，而「先建
动画、后改线型」是完全合理的顺序。

#### Scenario: 既有文档读作空清单

- **WHEN** 读入一份不含动画清单的既有文档
- **THEN** 校验通过，清单为空

#### Scenario: 非法清单被拒绝

- **WHEN** 校验一份动画 id 重复、时长为 0 或播放模式不合法的文档
- **THEN** 校验失败并给出对应的机器码

#### Scenario: 轨道随 Entity 一起消失

- **WHEN** 删除一个带轨道的图元
- **THEN** 它的轨道随之消失，不需要额外清理清单

### Requirement: CAD 复用同一份动画采样

CAD MUST 复用 `@compose-ui/animation` 的采样入口，MUST NOT 另写一份。该入口的签名 MUST 放宽
到「任何带 `entities` 的文档」，实现 MUST 保持不变——它本就只遍历 `entities`、只写 `entities`，
不认识 Frame、清单或文档的其余字段。

第二份实现的代价在于缓动求解：cubic-bezier 由 x 反解 t、牛顿法在近水平处发散退回二分，这段
数值代码没有任何 CAD 特有之处。

未被任何轨道命中的 Entity MUST 保持原对象引用。

#### Scenario: 同一个采样器同时服务两种文档

- **WHEN** 分别对页面文档与 CAD 文档采样同一形状的轨道
- **THEN** 两者得到同样的插值结果

#### Scenario: 未命中的对象保持引用

- **WHEN** 采样一份只有部分图元带轨道的 CAD 文档
- **THEN** 其余图元是原来的那个对象

### Requirement: CAD 动画采样只作用于渲染

图面 MUST 渲染采样后的文档，而命中、对象捕捉、框选与命令 MUST 继续读作者写下的那份文档。

动画是文档在某一时刻的**呈现**而不是文档本身。让命中跟着采样跑意味着用户要去点一个正在移动
的目标，而拖动的基准还会每帧变化。

#### Scenario: 播放中仍然点得中

- **WHEN** 某个图元正被动画驱动，用户点在它的作者坐标上
- **THEN** 命中成立

### Requirement: CAD 虚线偏移与 FLOW 命令

`CadStroke` MUST 支持可选的 `dashOffset`（世界单位），渲染时 MUST 与虚线间隔同样随缩放变化。

系统 MUST 提供 `FLOW`（别名 `FL`）命令：选中图元后为它们建立一条循环的虚线流动动画。命令
MUST 在图元没有线型时补上一个默认虚线——`stroke-dashoffset` 只对虚线有意义，实线上的偏移动画
在屏幕上没有任何变化，交付一个没有视觉效果的动画等于没交付。

轨道 MUST 从 0 走到**一个完整虚线周期**，使循环接缝处的图案与起点逐像素相同；取半个周期或
一个随手的常数会让每次循环闪一下。

#### Scenario: 一条命令得到一根流动的线

- **WHEN** 用户选中一条实线并执行 `FLOW`
- **THEN** 该线获得虚线线型与循环的偏移轨道
- **AND** 一次撤销回到执行之前

#### Scenario: 已有线型的图元保留自己的线型

- **WHEN** 对已经设置过线型的图元执行 `FLOW`
- **THEN** 线型不变，轨道按它自己的周期建立

### Requirement: CAD 画布播放动画

画布 MUST 在文档存在动画时按会话播放头推进并渲染采样结果，MUST NOT 把播放头写进文档——它与
视口、网格一样是会话级视图状态。

没有动画时 MUST NOT 起动逐帧循环。宿主 MUST 能关闭播放；依赖确定性画面的用例 MUST 显式关闭，
而不是去赌某一帧的相位。

#### Scenario: 有动画即播放

- **WHEN** 打开一份含流动动画的图纸
- **THEN** 虚线偏移随时间变化

#### Scenario: 宿主关闭播放

- **WHEN** 宿主关闭播放
- **THEN** 画面停在动画起点，且不起动逐帧循环
