# 设计说明

## 为什么淡入起点取 4 而不是直接把阈值抬到 8

判据是「满值的线之间隔多远」，答案是 8——与标尺细刻度同一个数。但**淡入区间是
`[T, 2T)`**，细档在 `2T` 处才满值，因此 `T` 必须取 8 的一半。

直接把 T 取成 8 会让 100% 缩放（细线间距正好 8px）的细档整档消失。这次改的是缩小的那一段，
`zoom ≥ 1` 必须逐像素不变，这条是边界条件而不是顺带的好处。

## 为什么必须同时补淡入

stride 按二次幂翻倍，每跨过一次阈值屏幕上一半的线在一帧内消失。阈值是 2px 时这事发生在
没人看得清的密度里，所以从来没暴露；让线更早退场之后它就变成一次显眼的闪动。
**提高间距与补淡入必须一起做**，只做前一半是拿一个新毛病换掉旧毛病。

## 骨架档的补足量是解出来的

设细档不透明度 `a`、骨架档 `b`，骨架线的合成值是 `a + b(1 − a)`。要它恒等于满值 `A`：

```
b = (A − a) / (1 − a)
```

`a = A` 时 `b = 0`——细档满值时骨架档根本不画，放大时的输出与改动前逐字相同。
少了这一步，两档叠加会让**每隔一根线深一档**，那是今天没有的新毛病。

这条公式同时用在色阶上：每一级要写入的不透明度都由「合成后要达到的那一级」减去下面已有的
墨算出。它管的是「下面已经有多少墨了」，跟那层墨是为了淡入还是为了分级无关。

## 为什么粗格是 `primaryLineEvery²` 而不是新加一个字段

调研（AutoCAD `GRIDMAJOR` 5、Inkscape 5、Photoshop 4、Illustrator 8、Excalidraw 5、
tldraw 每级 4）显示层间比集中在 4–5，**没有任何产品超过 10**。因此把 `primaryLineEvery`
提到 16 拿不到先例——一个大格里 16 个小格数不过来。要让大格变大，动作是**加一级**。

而加一级不需要新字段：网格本来就是自相似的，「主线的主线」就是层级的定义。
tldraw 的 `gridSteps` 是 1 / 4 / 16 / 64，正是 `4^k`。用 `primaryLineEvery^k` 表达层级，
既没有新词汇，也让用户改一个数就同时改掉两级的比例——那正是他想要的语义。

默认值 8 → 4 之后层级是 8 / 32 / 128 世界单位。128 也让 1280 宽的默认场景正好十格。

## 为什么主线不淡入

主线间距恒为细档的 `primaryLineEvery` 倍，而细档恒在 4–8px，因此主线恒在 16–32px、
粗格恒在 64–128px——**永远不会过密，也就永远不需要淡入**。

淡入对细纹理是对的，对结构是错的：**一条淡了一半的主线既不是主线也不是细线**。
（此前给主线配独立阈值加淡入试过一版，20% 缩放时一半主线 α=0.02、另一半 α=0.32，
屏幕上大格子变成「隔一条深一条淡」，大小还在 2 格和 4 格之间跳。）

## 线宽与浓度是一对，不能只改一个

墨量 = 浓度 × 宽度。宽度从 `1 CSS px` 改成 `1 / dpr`，浓度就要乘回 `dpr`，
否则 2× 屏上网格的存在感直接掉一半，用户会把「变细」读成「变淡」。

天花板同样按**墨量**比而不是按浓度比：场景描边仍是 1 CSS px，在 2× 屏上是两个物理像素，
墨量是 `0.45 × 2`。粗格补偿后是 `0.642 × 1`，仍只占它的 71%。只比浓度会误判。

落点也要从按 CSS 像素取整改成按**设备像素**取整：发丝线只有一个物理像素宽，落在半个
物理像素上会被摊成两条各半浓的线——那正好是「想要更细」的反面。1 CSS px 宽的线对这件事
不敏感，发丝线敏感；**细下去之后，这条以前无所谓的近似就变成可见的了。**

## 色阶为什么由对比度反解而不是手调

现状是四组互不相干的 hex+alpha，量下来深色的主线比细线强 1.53 倍、浅色只有 1.30 倍——
同一份图纸换个主题，「哪条是大格」的读法就变了。

每个主题只留一支墨，层级全交给 alpha，alpha 由目标对比度 1.25 / 1.50 / 1.80 反解。
两个主题命中同一组对比度，层级差因此天然一致。墨取的正是**场景描边**那一支，
统一之后整个 Stage 的结构灰只剩一支，而且天花板变得可说：
**网格最粗的一级必须明显低于场景描边**，否则用户会把网格线读成边界。

## 已知的未决项

- **浅色场景描边偏弱**：`--compose-scene-outline` 浅色是 42%（对比 1.974:1），深色 45%
  （2.412:1）——浅色的场景边界本来就比深色弱 18%。按它当天花板，粗格的余量只剩 1.14×。
  提到 52.6% 可命中与深色相同的 2.412:1。**不在本次范围**：它是场景描边的缺陷，
  独立决定，不改也能落，代价是浅色下大格与场景边界的区分偏弱。
- **标尺刻度线宽**：标尺是另一条渲染路径。网格细下去之后刻度若还是 1 CSS px，
  同一条世界坐标在标尺上会比在图面上粗一倍。本次一并改，见 tasks。
- **粗格改用线宽而不是不透明度分级**：tldraw 用 `isMajorLine ? 3 : 1`，在 1px 上比 20%
  的对比度差更好读。留作后手——三档不透明度真读不出层级时再动。
