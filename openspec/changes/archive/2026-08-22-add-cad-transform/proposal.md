# CAD 几何可编辑：MOVE、COPY 与拖动

## Why

画完之后除了删掉，什么都改不了。四条命令是 `LINE` / `ERASE` / `BLOCK` / `INSERT`，手势只有
取点、点选、框选——**没有移动，没有复制，没有拖动**。

这不只是缺一条命令。路线图把步骤 8「端口与导线」列为画图工具与示意图工具的分水岭，标题场景是：

> 拖动一台交换机，连着它的网线必须跟着走。

**这条场景现在根本跑不起来**：没有「拖动」这个动作。端口与导线的全部价值是「移动时导线跟着
走」，而移动不存在时，那条能力落地即无法验证，只会变成一条单元测试见过、用户见不到的东西。

因此本刀排在步骤 8 之前。

## What Changes

- **`MOVE` / `M`**：选择对象 → 基点 → 第二点，整次移动是一个事务。
- **`COPY` / `CO`**：同样的取点流程，但**重复取点**直到用户结束——AutoCAD 的 COPY 是连续的，
  放一个副本之后继续等下一个落点。
- **拖动已选中的图元**即移动，作为第二个入口而不是第二份事实来源：与 `MOVE` 派发同一条命令，
  撤销一步回到拖动之前。
- 位移求解走**已有的点求解管线**，因此捕捉、正交与网格吸附全部白拿。

## Impact

- Affected specs: `cad-document`
- Affected code: `@compose-ui/cad`、`@compose-ui/cad-canvas`
- 无文档协议变更：位移只改既有 Component 的坐标字段。
- 不含**夹点编辑**（拖端点改几何）：那是另一种交互范式，不是同一条纵向流程。
