# 变更：编辑器 chrome 密度与状态语汇

## 原因

`restructure-editor-chrome` 把 chrome 收成了一个大东西分三栏，纵向竖线从 8 条降到 4 条。
问题因此从**分割数量**变成了**每一块 chrome 自己的厚度与语汇**，量出来是四处：

- **同一个动作有两个入口，而且不在同一个地方。**收起左栏点场景组头右端的 `<`，想展开回来
  时那个按钮已经跟着组一起消失了，得去编辑器最左边找一条 **8px 宽**的把手；底栏根本没有
  这个入口。同一个动作三种答案，其中一种用户找不到。
- **顶栏右侧五个簇挨着排**，其中两个是长得一样的分段控件（模式、工作区），眼睛分不出哪个
  是哪个。保存按钮**多数时候是禁用的**，而「改没改过」标签上已经画着脏点。
- **面板头两侧各长各的**：左栏场景图 62px、右栏属性 119px（Dockview 标签 30 + 主体标题 52
  + 属性工具条 36），没有一条共同的规则；119px 相当于三行半属性被头吃掉。
- **工具栏行 49px 装 30px 的按钮**，19px 是纯留白且横贯整个画布宽度；行内 `aria-pressed`
  只有一种样式，**工具（单选）与开关（多选）长得完全一样**——屏幕上常年 3–5 个同样的蓝块，
  其中只有一个在回答「我此刻在什么工具里」，而相邻两个开关（组内间距 1px）亮起来会连成
  一整块 61px 宽的蓝色。

## 变更内容

### 收起入口收敛到顶栏

三个布局开关（左 / 底 / 右）常驻文档标签条右端，实心 = 展开、描边 = 收起。**开关的位置不随
面板存亡而移动**——这是 8px 把手唯一解决不了、也是它存在的全部理由。`WorkspaceSideHandle`
与组头上的两个折叠按钮一并删除：「一个动作只给一个入口」是这个仓库自己的规则，工具栏的形状
split button、框选判定模式菜单都是照它删掉的。底栏因此第一次有了显式的折叠入口。

### 顶栏先减后分段

- **保存按钮删掉**，改为动作目录里的 `document.save`（默认仍绑 `Cmd/Ctrl+S`）。今天那个键是
  硬接在 `compose-editor.tsx` 的按键处理里的，既不在目录也不在键位页——删按钮之前必须先补，
  否则它的入口只剩一个记不住且改不了的快捷键。
- **管理菜单并进工作区切换器的活动段**（`页面 ▾`）：它管的永远是当前那个工作区。
- **模式切换器挪走**（见下）。
- 剩下的按作用域收进两段：**视图**（三个布局开关）｜ **应用**（工作区切换 ▾、设置）。

### 模式切换器搬到画布工具栏行尾

「设计 / 动画」从文档标签条右端搬到画布工具栏**行尾**，与货架之间一条竖线。它**仍是带文字的
两段控件，MUST NOT 做成图标 toggle**，也 **MUST NOT 属于货架**：

- 模式改的是「拖动的结果写到哪里」（关键帧还是 `LayoutItem`），与吸附、网格那些「落点怎么被
  修正」的开关不是一回事。做成同形的 toggle 就是让**两个长得一样的东西做不同的事**。
- 货架上的每一格用户都能右键移除，而**模式必须始终可见**——移掉之后没有任何东西告诉用户
  他身在动画模式。
- 同时注册 `document.toggleAnimationMode`：一个这么重要的开关不该只有一个鼠标入口。

代价写在明处：绘图工作区在 1280 默认窗口下因此超 31px，货架末尾的「文字」收进「更多」。

### 面板头统一成「标签 + 一条 chrome」

左右两侧的面板头收成同一条规则：一条 30px 的 Dockview 标签，加**至多一条** chrome 行。
属性面板那条 52px 的主体标题行删掉——对象名并进标签本身（`属性 · 矩形`），而它行里那簇动作
（实例 Apply/Revert、添加能力）并进搜索那一行的右端，为此给 `ComposePropertyPanelRoot` 加一个
`toolbarActions` 槽。**右栏 119 → 66px**；场景图本来就是这个形状（30 + 32），不动。

原稿说的「30px」要把面板动作渲染进 Dockview 组头（portal），那是另一件事；而在动作并进 chrome
行之后，再把搜索折成图标只多省 6px，却要动 `property-panel` 与 `scene-tree` 两个包的搜索交互。
两样都留作后续。

### 工具栏行与按下态

- 行高 `min-h-12`（49px）→ **36px**（30 + 3 + 3）：按钮尺寸、间距、命中区全不动，净得 13px
  画布高度。分隔线 24 → 18px 并提亮——它今天几乎和按钮一样高，读起来像又一颗按钮。
- **按下态按角色分成两种**：工具（单选）保留实心底但**内缩 2px**（26×26），相邻两块之间因此
  从 1px 变成 5px；开关（多选）**不给底**，只把图标点亮成更亮的 accent、静息态压到
  `text-muted`，于是开与关既是色相差也是明度差。悬停跟着内缩到与工具按下相同的形状。
- 内缩**不花任何宽度**，这是它压过「把间距调大」的理由：绘图 15 格、组内 11 处间距，
  1 → 3px 要 22px，而绘图的余量在放进模式切换器之后已经是负的。

### 不做

- **工作区切换器按数量折成下拉**：宽度无界是真问题，但它要改「切换器 MUST 是 `radiogroup`，
  方向键按索引循环」这条已写下的 MUST，与密度正交，留作后续。
- **第四颗布局开关（只看画布）**：它在管理菜单里有入口，本变更不动。
- 图标重画：20px 幅面与 1.5 描边是一对，改幅面要连整套图标一起重画。

## 影响

- 规范：`editor-workspace-layout`（MODIFIED 6 条、ADDED 2 条）、`editor-preferences`
  （MODIFIED 1 条、ADDED 1 条）。
- 代码：`packages/editor`（`workspace-layout/`、文档标签条、面板头、`stage-toolbar/`、
  `editor-preferences/`、`styles.css`）。`stage`、`stage-engine`、`core`、`commands`、
  `component-library` 不动。
- 端到端：`editor-workspace.spec.ts`、`toolbar-shelf.spec.ts` 要跟着改；**整窗黄金图全部
  重录**——工具栏行矮 13px 会把画布里的一切上移，面板头与顶栏也都在取景里。这是本变更里
  最花时间的一步。
