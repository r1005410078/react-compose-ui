## 3. 四条区域运算

- [x] 3.1 `core/curve-boolean.ts`：判据落在**边**上而不是面上——每条半边取它那一侧元胞里的
      一点。原设计是「枚举全部有界面」，**落地时推翻**：绕半边只能绕出连通分量的环，一个形状
      整个落在另一个内部时两者不连通，「大的挖掉小的」那块元胞根本没有代表。判别性用例是
      「矩形减掉里面一个小矩形」
- [x] 3.2 取样点让开的量由「边中点到其余每一条边的最近距离」推出，取一半。**不用最大内切圆**
      （那要一次四叉细分，细长条上要跑好几秒），也**不用固定小量**（细长元胞上会跨到另一边）
      > 评审时补的一刀：这个量还要被**这条边自己的曲率**钳住（弧取半径）。上面那条距离只保证
      > 这个半径内没有**别的**边，而弧会自己绕回来——一个远离其余几何的小圆，距离是它到外框的
      > 那一段，让开一半直接跨到圆的另一侧，「大矩形减掉里面一个小圆」于是**没有洞而且不报错**。
      > 3.6 那条弧用例挡不住它：那个圆压在矩形边缘上、被切成几段，每段中点离别的边都很近。
      > 判别性用例要的是一个**整个在内部**且**离每条边都远**的圆
- [x] 3.3 分类：逐操作数问 `isPointInsideComposeCurve`，四条运算 MUST 只差一个谓词；
      操作数多于两个时不得退化成两两归约
- [x] 3.4 边界：一条半边这一侧留、对面没留即在边界上；沿边界绕环 MUST 按**半边**限定
      （`traceLoop` 的过滤器从子边级放宽成半边级），按子边限定会顺着反向那一个走出去
- [x] 3.5 三支结果：求出了几何 / 没有面积 / 求解退化，MUST 互相可分
- [x] 3.6 单测：两矩形并集落 `polyline`、矩形减圆、圆整个落在矩形内得到 `evenodd` 的岛、
      三形状异或、不相交求交集报「没有面积」、**沿网格共享一条完整边的两个矩形求并集**
      （判别性用例——它正是边裁剪要特判而面分类不用特判的那一档）
- [x] 3.7 `stage-engine/commands/curve-boolean.ts`：世界投影（`stageWorldOutline`）、
