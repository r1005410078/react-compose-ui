# 变更：导线有自己的 Preset —— 一次回路的红色粗实线

## 原因

`WIRE` 画出来的东西和 `LINE` 画出来的东西**长得一模一样**——两者共用 `curve` Preset，因此
共用 `DEFAULT_CURVE_PROPS`。而它们不是一回事：导线带 `Wire`，两端可以绑到端口，符号一移动
它就跟着走。这个差别在屏幕上完全不可见。

**这个产品画的是一次接线图**，因此答案要从那个领域取，而不是从 PCB 原理图工具取：

- **红 = 合闸/带电**是变电站监控画面的通行惯例。储能、光伏这类一次接线图画的是**正常运行**的
  系统，整条一次回路本来就是带电的——实机上通篇是红。
- **绿 = 分闸/停电**，正好相反。PCB 原理图工具（KiCad）用绿画导线，那是另一个领域的惯例：
  那张图上颜色是空闲的语义通道，而这里不是。
- 母线与线路另按**电压等级**着色，色表因项目而异，因此不内置。

电气制图区分主回路的另一个手段是**线宽**：一次回路粗实线，二次回路与标注细实线。两者一起用。

## 变更内容

- 新增 `wire` Entity Preset，成为 `curve` 物料的**第四个起点**（同一个 Renderer、同样带
  `Curve`，差别只在默认描边）。
- `wire` 的默认描边是 `stroke: '#ff3b30'` + `strokeWidth: 2`，线帽与 marker 沿用。
  取 `#ff3b30` 而不是纯红 `#ff0000`：两者都是红，但纯红在深色画布上视觉会「振」，而这个值在
  编辑画布（≈5.1:1）与浅底页面（≈3.6:1）上都过图形元素的 3:1 门槛——场景背景默认透明，导线
  是会被发布出去的真实像素。
- 颜色**仍然留给数据绑定**：`stroke` 是可绑定的 Renderer prop，项目要做拓扑着色（带电红、
  停电绿）时绑它即可；红只是「还没绑」这一档的取值，而它取的正是最常见的那一档。
- `WIRE` 命令落地时按提交效果上的 `wire` 标记挑这个 Preset，与 `ARROW` 挑 `arrow` Preset
  是同一条既有边界（引擎不认识 Preset id）。
- `wire` 默认隐藏于 Palette：它由 `WIRE` 命令产出，Palette 里再放一个入口会得到一条**没有
  任何端口绑定**的粗线，而粗线正在宣称它是主回路。

## 影响

- 受影响的规范：`basic-materials`、`stage`
- 受影响的代码：`packages/materials/src/curve/{defaults,definition}.tsx`、
  `packages/stage/src/drafting/drafting-entity.ts`
- **不影响既有文档**：改的是新建时的种子值，已落地的导线保留自己的描边。
- 导线的墨色变红之后，**图面上「失效端点」的记号不能再用红**（红记号画在红线上等于没画），
  已改为琥珀；它与捕捉标记的橙相近，但两者形状不同（端点是圆、捕捉是方框），符合这块画布
  「形状先分开、颜色再分开」的既有规则。
- `LINE` / `PLINE` / `RECTANGLE` / `CIRCLE` / `ARC` / `ARROW` 一个字都不改。
- **默认色不在本变更范围内**。`#d8e2f1` 是按编辑器深底挑的近白，而场景背景默认透明，落在
  浅底页面上接近隐形——这是**所有**制图几何共同的问题，不是导线独有的，留在
  `docs/drafting-interaction-sdd.md` §6 待确认。
