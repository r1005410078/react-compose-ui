## ADDED Requirements

### Requirement: 角度约束的持有、切换与呈现

Stage MUST 持有角度约束的三态（关 / 正交 / 极轴）与极轴的增量角，且 MUST NOT 把它们写进
文档：它是「怎么画」而不是「画了什么」，与网格设置同一条判断。

**默认 MUST 是极轴。** 它不挡任何画法——只在光标靠近某条射线时才吸——因此可以默认开着；而
只有默认开着，最常用的那个约束才真的被用上。正交 MUST NOT 默认开启：它无条件投影，一开就
画不了斜线。

**默认增量角 MUST 是 45°。** 这是对 AutoCAD 默认值（90°）的有意偏离，理由是前提不同：
AutoCAD 的极轴默认是关的，我们默认是开的。默认开着时增量角要覆盖用户真会画的方向，而 90°
漏掉的正是接线图上那条斜引线；45° 只多四条射线，容差是几个屏幕像素，误吸的代价很小。

状态 MUST 是**可选受控**：宿主给出 `angleConstraint` 时由宿主持有（工具栏要画按下态，而
事实来源只能有一份），不给时由 Stage 自己持有。`stage` 是可独立嵌入的包，MUST NOT 要求每个
宿主都接一个工具栏。

键盘：`F8` MUST 切正交、`F10` MUST 切极轴，与 AutoCAD 一致。按下**已经生效**的那一个 MUST
关闭角度约束——三态互斥，因此这两个键是同一个单选组的两个成员。

命令行的状态标记 MUST 说出此刻是哪一态，且三态都要渲染：只在开启时出现会让用户无法确认它
现在是关的。

极轴的命中容差 MUST 与拾取框、特征点靶区同一个量纲（屏幕像素），并 MUST 复用同一个
`snapRadius`——「多近算在上面」在这个产品里只该有一个数。

**命中时 MUST 画一条追踪射线**，从参考点穿过落点。不画的话用户只看到点「粘」到了某个方向
上，说不清是自己手稳还是有东西在吸。它 MUST 属于**标注**那一族（与角度弧的 0° 参考射线同色
同点画）而 MUST NOT 属于预览那一族：它说的是「你正沿着这条线」，不是「松手会变成什么」。

追踪射线画不画 MUST 读管线上报的那一份命中，MUST NOT 自己再判一次——各判一次的症状是
「画了射线但点没落在上面」。

角度约束 MUST 作用于所有走 `resolveComposePoint` 的取点：绘图命令与夹点编辑。实体拖动走的是
另一条路径（对齐吸附），不在本条范围内。

#### Scenario: 默认是极轴

- **WHEN** Stage 刚挂载、宿主没有给出角度约束
- **THEN** 角度约束是极轴，增量角 45°

#### Scenario: 靠近射线时吸住并画出射线

- **WHEN** `LINE` 取过第一个点，指针移到接近 45° 的方向上
- **THEN** 落点落在 45° 射线上，且覆盖层上出现一条追踪射线
- **WHEN** 指针移到 20° 附近
- **THEN** 落点不被投影，追踪射线消失

#### Scenario: F8 切正交，再按一次关掉

- **WHEN** 默认状态下按 `F8`
- **THEN** 角度约束变成正交，极轴随之关闭
- **WHEN** 再按一次 `F8`
- **THEN** 角度约束关闭

#### Scenario: 状态标记三态都渲染

- **WHEN** 角度约束关闭
- **THEN** 命令行仍然显示这个标记，且说出它是关的
