## ADDED Requirements

### Requirement: 可进入节点与进入意图

SceneTree MUST 支持宿主把节点标记为「可进入」，并在这些行上呈现一个常驻的进入控件。
该控件 MUST 是具备可访问名称的按钮，排在可见性与锁定控件**之后**。用户点击该控件、双击该行，
或在该行右键菜单的首项执行进入时，组件 MUST 只发出一次 `{ type: 'enter'; nodeId }` 操作意图，
MUST NOT 自行改变节点数据、选择或展开状态。未标记为可进入的节点 MUST NOT 呈现该控件，
双击它们 MUST NOT 发出进入意图，且观感与既有行为保持不变。

#### Scenario: 点击进入控件

- **WHEN** 用户点击一个可进入节点行上的进入控件
- **THEN** 组件发出一次携带该节点 ID 的 `enter` 操作意图
- **AND** 不发出选择、展开或结构操作意图

#### Scenario: 双击可进入的行

- **WHEN** 用户双击一个可进入节点行的名称或图标区域
- **THEN** 组件发出一次携带该节点 ID 的 `enter` 操作意图
- **AND** 该行不进入重命名状态

#### Scenario: 普通节点不受影响

- **WHEN** 树中存在未标记为可进入的节点
- **THEN** 这些行不呈现进入控件
- **AND** 双击它们不发出 `enter` 操作意图

#### Scenario: 右键菜单进入

- **WHEN** 用户在可进入节点上打开命令菜单
- **THEN** 菜单首项为进入命令并与既有命令分组之间有分隔
- **AND** 执行它发出与进入控件相同的 `enter` 操作意图

### Requirement: 来路出口行与退出意图

SceneTree MUST 支持宿主把某个节点标记为这棵树的来路出口。该行 MUST 在**行首**呈现一个具备可访问
名称的返回控件（与进入控件的朝向相反），并 MUST 以整行铺满、不内缩、不加圆角的头部底色呈现——
普通行的选中态是内缩的圆角胶囊，两者形状必须可分。返回控件被激活时组件 MUST 只发出一次
`{ type: 'exit'; nodeId }` 操作意图，MUST NOT 自行改变选择、展开或节点数据。未标记的节点 MUST NOT
呈现返回控件，其观感与既有行为保持不变。

#### Scenario: 从根行返回上一层

- **WHEN** 用户点击来路出口行行首的返回控件
- **THEN** 组件发出一次携带该节点 ID 的 `exit` 操作意图
- **AND** 不发出选择、展开或结构操作意图

#### Scenario: 出口行呈现头部底色

- **WHEN** 某个节点被标记为来路出口
- **THEN** 该行以整行铺满的头部底色呈现，可与内缩圆角的选中态区分

#### Scenario: 普通行不受影响

- **WHEN** 树中存在未标记为来路出口的节点
- **THEN** 这些行不呈现返回控件，也不呈现头部底色
